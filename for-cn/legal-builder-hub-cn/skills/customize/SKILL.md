# /customize

## 何时运行

用户输入了 `/legal-builder-hub-cn:customize`。他们想改 Builder Hub 档案里的某个东西 —— 一个被监控的仓库、更新通知偏好、推荐用的执业领域 —— 而不想重跑整个冷启动访谈，也不想手工编辑 YAML。

## 做什么

1. **读取配置。** 读取 `~/.claude/plugins/config/claude-for-legal-cn/legal-builder-hub-cn/CLAUDE.md`（以及上一级的 `~/.claude/plugins/config/claude-for-legal-cn/company-profile.md`）。如果插件配置不存在或仍含 `[待填写]` 标记，说：

   > 你还没有运行初始化。请先运行 `/legal-builder-hub-cn:cold-start-interview` —— customize 用于调整已经存在的档案。

2. **展示可定制地图。** 列出档案里的内容，分组，并给出当前值的一行摘要：

   - **公司 / 你是谁** —— 名称、行业、法域、阶段、执业场景 *(在全部 12 个插件间共享 —— 变更通过 `company-profile.md` 流转)*
   - **你的执业档案** —— 覆盖的执业领域，用于推荐社区技能
   - **已安装初始包** —— 通过 hub 安装了哪些插件和技能，安装来源
   - **被监控的仓库** —— hub 从中拉取社区技能的 GitHub 仓库 / URL（含 gitee 镜像）
   - **更新偏好** —— 检查节奏（每日 / 每周 / 按需）、通知渠道（Slack / 会话内）、自动更新 vs 提示
   - **QA 严格度** —— `/skills-qa` 在安装前对候选技能标记问题的激进程度（宽松 / 中等 / 严格），以及启用哪些失败模式检查
   - **技能安装默认** —— 安装范围（用户 / 项目）、安装前是否自动运行 `/skills-qa`
   - **集成** —— Slack / 文档存储状态、回退方式

3. **问他们要改什么。**

   > 你想调整什么？挑一个章节，或用你自己的话描述这个变更。

4. **执行变更。** 展示当前值，询问新值，解释下游影响，确认，写入配置。

   示例：
   - *新增一个被监控仓库：* "`/registry-browser` 以后会把这个仓库与现有仓库一起搜索。`/auto-updater` 下次运行时也会检查它。"
   - *QA 严格度 严格 → 中等：* "`/skills-qa` 会报告同样的发现，但中等档的发现不会在未经你确认时阻止安装。"
   - *自动更新 开 → 关：* "hub 之后会在应用更新前提示你，而不是自动应用。"

5. **共享档案的变更**（公司名、行业、法域、执业场景、阶段）：写入 `~/.claude/plugins/config/claude-for-legal-cn/company-profile.md`，并注明：

   > 这个变更影响全部 12 个插件 —— 任何读取你法域足迹的插件现在看到 [新值]。

6. **收尾。**

   > 完成。你的下一次输出会体现这个变更。还有别的吗？随时可以运行 `/legal-builder-hub-cn:customize`。

## 护栏

- **绝不删除章节。** 如果用户想「移除」一个被监控仓库，提议标记为 `[已暂停]`，并说明暂停会保留安装历史但停止更新检查。
- **标记内部不一致。** 如果变更会导致档案不一致（例如自动更新开 + QA 严格度关；或执业档案与任何已安装插件不匹配），标记这种张力。
- **标记护栏降级。** 法律技能设计框架检查（相关参数与法定失败模式检查、信任面检查）正是 `/skills-qa` 存在的目的 —— 关掉它们就失去意义。如果用户想降低严格度，推荐中等档而不是禁用检查。
- **一次只改一个地方。** 不要重新问整个访谈。

## 转换说明（质量自检）

- **A 级直转**：变更流程（读配置 → 展示地图 → 单项修改 → 共享档案联动 → 护栏），包括「绝不删除章节」「标记不一致」「不过度降低护栏」「一次一项」全部保留。
- **B 级大改**：路径改为 `claude-for-legal-cn/legal-builder-hub-cn`；命令改为 `/legal-builder-hub-cn:customize`；「被监控仓库」说明补充 gitee 镜像与国内技能市场；角色改为「自定义辅导」用法。
- **D 级新增**：无。
- **明确不做**：不涉及实体法内容；安全机制保留。
