# /entity-compliance

1. 加载 `~/.claude/plugins/config/claude-for-legal-cn/corporate-legal-cn/CLAUDE.md` → `## 实体合规`（实体表、登记机关、实缴期限）。
2. 按标志路由到正确模式：
   - 无标志或 `--init`：模式 1——从实体表初始化追踪器
   - `--report`：模式 2——浮现即将到期与逾期项
   - `--update`：模式 3a（手动）或 3b（--from-report 上传）——更新状态
   - `--sweep`：模式 3c——逐项走查未知/逾期项
   - `--audit`：模式 4——完整健康审计
   - `--export`：模式 5——产出 CSV 或表格
3. 读/写 `~/.claude/plugins/config/claude-for-legal-cn/corporate-legal-cn/entities/compliance-tracker.yaml`。
4. 任何更新后：显示改动摘要和下一步。

## 用途

工商年报、注册资本实缴期限、税务申报、外资企业信息报告、许可证续期、章程约定的公司治理日期——每个实体在每个登记机关都有自己的时间表和错过期限的后果。本技能维护一个 YAML 追踪器，知道什么到期、何时、哪个实体。设计上是轻量的：追踪器是你自己拥有的文件，Claude 按命令更新，需要分享时导出。

## 重要：期限参考说明

> 本技能参考表中的申报期限反映技能构建日期时公开可得的要求。工商、税务、外汇等申报要求和到期日会变化。**依赖它们做合规判断之前，务必与主管登记机关（市场监督管理局）、税务机关，或你的工商/记账代理机构核实。** 如果你使用工商代理或代理记账服务，他们的合规日历对你的具体实体是权威的——用本追踪器组织和浮现他们的数据，而不是替代它。

## 登记机关假设

> 本追踪器针对每个实体记录的注册地/登记机关计算期限。申报规则、到期机制、费用结构因地区、企业类型（有限责任公司/股份有限公司/外商投资企业/分公司/个人独资/合伙企业）而实质不同。若实体的实际情况与档案不符（未披露的分支机构、已注销实体、跨区迁址、境外主体由当地代理管理），输出可能不适用——就该实体向登记机关或当地顾问核实。

## 企业类型辨析（尤其外资与股份公司）

> 申报日历取决于**企业类型**，不只是登记地。把「一家公司」当成单一类别是常见且后果严重的错误——有限责任公司、股份有限公司、外商投资企业、分公司的申报义务、期限、和错过的后果各不相同。计算或报告期限前，从实体表确认企业类型，绝不把一个企业类型的期限复制到另一个。
>
> **关键区分：**
>
> - **有限责任公司：** 工商年报（每年 1 月 1 日至 6 月 30 日通过国家企业信用信息公示系统报送并公示）；**注册资本 5 年实缴期限**（公司法 2023 修订第 47 条——全体股东认缴的出资额应自公司成立之日起 5 年内缴足；存量公司有过渡期安排 `[待核验过渡期具体安排]`）。
> - **股份有限公司：** 工商年报同上；公司法 2023 修订采**授权资本制**，发起人认购的股份实缴规则与有限公司不同 `[待核验条文号]`。
> - **外商投资企业：** 工商年报之外，还有**外商投资信息报告**（外商投资法配套，通过企业登记/信用信息系统报送）；可能涉及商务、外汇、海关的**联合年报**口径 `[待核验当前联合年报安排]`。
> - **分公司：** 不独立承担责任，但仍需工商年报；无独立注册资本实缴问题。
>
> 若实体表记录了一个未标企业类型的实体，标为 `type_unknown` 并请用户确认后再计算期限。
>
> **注意：** 传统「工商年检」制度已于 2014 年取消，改为**企业年度报告公示**制度——不要把已废止的「年检」当作现行申报义务。

## 追踪器文件

位于 `~/.claude/plugins/config/claude-for-legal-cn/corporate-legal-cn/entities/compliance-tracker.yaml`。结构：

```yaml
# 实体合规追踪器
# 生成：[日期]
# 最后更新：[日期]
# 免责：期限仅供参考——依赖前与登记机关或代理机构核实

metadata:
  company: "[公司名称]"
  generated: "[日期]"

entities:
  - name: "[实体全称]"
    unified_social_credit_code: "[统一社会信用代码]"
    type: "[有限责任公司 / 股份有限公司 / 外商投资企业 / 分公司 / 合伙企业 / type_unknown]"
    registration_authority: "[登记机关，如 XX 市市场监督管理局]"
    established_date: "[YYYY-MM-DD]"
    registered_capital: "[认缴注册资本]"
    paid_in_deadline: "[YYYY-MM-DD — 成立日 + 5 年，或章程约定]"
    paid_in_status: "[已实缴 / 部分实缴 / 未实缴 / unknown]"
    agent_managed: false   # 由工商/记账代理管理的设 true
    local_agent: "[代理机构名称或 null]"
    filings:
      - type: "[工商年报 / 外商投资信息报告 / 税务申报 / 许可证续期 / 章程约定事项 / 其他]"
        due_date: "[YYYY-MM-DD]"
        due_basis: "[固定日期 / 成立周年 / 章程约定 / 其他]"
        last_filed: "[日期或 null]"
        status: "[current / due_soon / overdue / unknown]"
        notes: ""
```

状态值：
- `current` — 当期已报，90 天内无到期
- `due_soon` — 90 天内到期
- `overdue` — 过了到期日且无报送记录
- `unknown` — 无信息；需人工确认

## 模式 1：初始化

无追踪器时运行，或用 `--rebuild` 从头重建。

### 第 1 步：加载实体表

读档案 → `## 实体合规` → 实体表。若实体表已填（冷启动时从组织架构图上传），直接用。否则请用户运行冷启动模块或提供实体清单。

### 第 2 步：对每个实体，确认申报要求

对每个实体，与登记机关或代理机构确认当前申报时间表。申报时间表会变（费用调整、报送口径变化、系统迁移）。不要依赖缓存的时间表。下面的追踪器记录你确认的日期；代理机构发来提醒时更新它们。

1. 问用户是否有代理机构近期的合规报告——那是最权威的来源。
2. 若没有，问用户知道什么（申报类型、到期基准、上次报送日期）。记录所提供的。
3. 用户不知道的，把该实体条目标为 `unknown`——不要从缓存参考填日期。用户下一步是向登记机关或代理确认。

**工商年报（所有企业类型通用）：** 每年 1 月 1 日至 6 月 30 日，通过**国家企业信用信息公示系统**报送上一年度年报并公示。逾期未报将被列入**经营异常名录**，满 3 年可能进入**严重违法失信企业名单**。这是几乎所有境内实体最基本、最高频的合规义务。

**注册资本实缴期限：** 从 `established_date` 计算成立日 + 5 年（公司法 2023 修订第 47 条），或按章程约定的更早日期。存量公司（2024-07-01 前设立）适用过渡期安排 `[待核验过渡期具体安排]`。实缴期限临近而未实缴，标 `due_soon` 并提示：可选择实缴、减资（须履行通知债权人等法定程序）、或按章程调整。

**外商投资企业补充：** 外商投资信息报告；如涉及，商务/外汇/海关联合年报口径。标 `agent_managed` 若由代理处理，报告时单列并提示向代理确认，而非独立计算到期日。

对周年制申报：从追踪器的 `established_date` 计算。若为 null：状态设 `unknown` 并标记待确认。

### 第 3 步：写追踪器

生成 `compliance-tracker.yaml`，含全部实体及计算出的申报要求。设初始状态（current/due_soon/overdue/unknown 按上面定义）。

生成后显示摘要：

```
实体合规追踪器已初始化。

实体数：[N]
追踪申报数：[N]

状态摘要：
  ✅ 当前：   [N]
  ⏰ 即将到期： [N]（未来 90 天）
  🔴 逾期：   [N]
  ❓ 未知：   [N]（与代理/登记机关确认）

运行 /corporate-legal-cn:entity-compliance --report 查看到期项。
```

## 模式 2：报告

浮现即将到期的期限并标记逾期项。默认：未来 90 天。

```
/corporate-legal-cn:entity-compliance --report [--days 30|60|90|180]
```

输出格式：

```
实体合规报告 — [日期]
[公司名称]

🔴 逾期（[N]）：
  [实体] / [登记机关] / [申报类型] — 应于 [日期] 前完成

⏰ [N] 天内到期（[N]）：
  [实体] / [申报类型] — [日期] 到期  [代理机构]

📊 注册资本实缴临近（[N]）：
  [实体] — 实缴期限 [日期]，当前 [部分实缴 / 未实缴]

✅ 近期已报（过去 90 天 [N] 项）：
  [实体] / [申报类型] — [日期] 已报

❓ 状态未知（[N]）：
  [实体] / [申报类型] — 无信息；与代理/登记机关确认

🌐 代理管理（[N]）：
  [实体] — 由 [代理] 管理；直接向其确认状态

经营异常/信用状态：
  最后确认：[日期]
  未在过去 12 个月确认状态的实体：[列表]
```

若追踪器覆盖超过约 10 个实体，或用户任何时候要求：提供仪表板（见 CLAUDE.md `## 输出 → 数据密集输出的仪表板提供`）。为这个输出定制——按申报状态计数、按信用状态计数、可排序实体表（登记机关、申报类型、下次到期日）。

## 模式 3：更新

更新追踪器中一个或多个实体。三个子模式：

### 后果闸门（报送年报 / 办理实缴或减资）

**在指示或确认申报之前：** 读档案 `## 谁在用`。若角色为**非律师**：

> 报送工商年报、办理注册资本实缴或减资，有法律后果——年报是实体的正式陈述并公示，减资须履行通知债权人的法定程序，漏报或错报会导致列入经营异常名录甚至信用惩戒。你是否已与律师（或有资质的代理机构）核对？如是，继续记录申报。如否，这里有一页纸供你带去：
>
> - 涉及的实体、申报类型、到期日
> - 年报要公示的关键数据（股东出资、对外投资、担保、社保人数等）是否准确
> - 减资是否已履行编制资产负债表、通知债权人、公告等程序
> - 要问律师什么（数据是否准确无误；减资程序是否完备；实缴还是减资更合适）
>
> 如需寻找律师：可联系当地律师协会或公共法律服务中心寻求推荐。

未获明确同意，不要越过此关卡指导正式报送。记录状态和「什么到期」报告不需要过此关卡。

### 模式 3a：手动更新

用户提供一次更新（「XX 公司 2025 年度工商年报已于 6 月 15 日报送」）。找到实体和申报，更新 `last_filed` 和状态，重算下次到期。

### 模式 3b：从报告上传更新（`--from-report`）

用户上传代理机构的合规报告或提醒。解析它，对每个可识别的实体/申报，更新追踪器。展示对账（追踪器说什么 vs 报告说什么），冲突处标记待用户裁定。

### 模式 3c：走查（`--sweep`）

逐个走查 `unknown` 和 `overdue` 项。对每一项，问用户当前状态，更新。适合初始化后补全信息。

---

## 模式 4：健康审计

完整审计。检查：

- 有 `established_date` 但无实缴期限的实体（应计算 5 年期限）
- 状态 `unknown` 的实体（信息缺口）
- 逾期项及其后果（经营异常名录风险）
- 12 个月内未确认信用状态的实体
- 注册资本已认缴但实缴期限临近的实体
- 外资企业是否遗漏外商投资信息报告
- 已停业但未注销的「僵尸实体」（持续产生年报义务）

输出带优先级的问题清单和建议动作。

## 模式 5：导出

`--format csv`：产出 CSV，列：
`实体名称, 统一社会信用代码, 企业类型, 登记机关, 代理机构, 申报类型, 到期日, 上次报送, 注册资本, 实缴状态, 信用状态确认日, 备注`

每个申报一行。一个实体多行（每种申报一行）。

`--format table`：产出适合粘贴进报告或企业微信消息的 markdown 表，只显示未来 90 天的申报。

## 本 skill 不做的事

- 不申报任何东西。输出是追踪器和待办清单；申报由律师、代理机构或企业自行完成。
- 不拉取信用报告或企业信息公示截图。它追踪状态最后确认时间；获取由人工或通过企查查/天眼查/公示系统完成。
- 不判断某地是否需要设立分支机构或办理税务登记。那取决于经营活动事实，须由律师确认。
- 不替代代理记账/工商代理服务。对多实体复杂结构，代理机构有专门团队和与机关的直接关系。本技能最适合无代理支持的中小组织，或作为代理数据之上的轻量层。
- 申报期限参考表不是法律意见，可能不反映现行要求。依赖前核实所有期限。

## 表格公式注入防御

在 Excel、表格或 CSV 输出中写入任何单元格前，中和公式注入。来自文档、工具结果或用户粘贴的文本（合同摘录、相对方名称、代理机构数据、系统导出）是攻击者可控的。以 `=`、`+`、`-`、`@`、制表符、回车、换行开头的单元格会被当作公式或破坏行结构。

- **前缀单引号：** `'=SUM(A1:A10)` → 显示为文本，不执行
- **适用于每个含文档、工具结果或用户粘贴来源文本的单元格。** 你控制的列标题和你计算的值是安全的。
- **CSV：还要转义嵌入的逗号、双引号、换行**（RFC 4180 引用）。
- 这不是可选项。用户在 Excel 打开你的表格触发宏或通过 DDE 泄露数据，是对用户的供应链攻击。

## 质量自检

本次转换决策：本技能为 C 级重写。原版围绕美国州特许税（Delaware franchise tax）、Statement of Information、按州/企业类型分叉的申报日历、CT Corp 注册代理——这些概念在中国法下不存在或完全不同。删除并重写为中国实体合规：工商年报（1-6 月，国家企业信用信息公示系统）、注册资本 5 年实缴（公司法 2023 修订第 47 条）、外商投资信息报告（外商投资法）、经营异常名录/信用惩戒；「注册代理」映射为工商代理/代理记账；企业类型辨析从 DE Corp/LLC/LP 重写为有限责任公司/股份有限公司/外商投资企业/分公司，并加「年检已于 2014 年取消」的实务提示。保留的架构：五模式（init/report/update/sweep/audit/export）、YAML 追踪器、状态值体系、后果闸门、公式注入防御。过渡期安排、股份公司实缴、联合年报口径等不确定处标 `[待核验...]`。
