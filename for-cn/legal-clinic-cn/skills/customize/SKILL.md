# /customize

## 何时运行

用户输入了 `/legal-clinic-cn:customize`。他/她（通常是指导老师，偶尔是学生）想在诊所档案里改一件事 —— 一处办案地、监督模式、
一个纠纷类型模板、学期滚动 —— 而不重跑整套 cold-start，也不手改 YAML。

## 该做什么

1. **读档案。** 读 `~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/CLAUDE.md`。若不存在或仍含 `[待填写]`，说：

   > 你还没跑 setup。先运行 `/legal-clinic-cn:cold-start-interview` —— customize 用于调整已有的档案。

2. **展示可定制地图。** 按分组列出档案里的内容与当前值一行摘要：

   - **诊所档案** —— 诊所名称、依托高校、指导老师、办案的纠纷类型、案件量上限
   - **办案地** —— 主要法院、劳动人事争议仲裁委员会、行政机关、地方规定路径
   - **监督模式** —— 正式队列 / 可配置标记 / 轻监督；若正式队列，谁审什么才能出
   - **纠纷类型模板** —— 启用了哪些类型（劳动、婚姻家事、交通事故、民间借贷、租赁、消费、刑辩援助等）与地方覆盖
   - **学期** —— 当前学期、在册学生、滚动规则、交接备忘格式
   - **输出护栏** —— 面向受援人的通俗语言标准、期限预警规则、保密标注
   - **种子文件** —— 诊所工作手册、地方规定、样本文书、模板信函、样本备忘、表格库
   - **产出** —— 老师指引格式、受援人信函模板、备忘骨架
   - **工作流** —— 案件目录、期限台账位置、审核队列频道
   - **集成** —— 文档存储 / 企业微信 / 钉钉 / 法规检索 / 案管的状态与回退

3. **问要改哪项。**

   > 你想调什么？选一节，或用你自己的话说要改什么。

4. **做改动。** 展示当前值 → 问新值 → 说明下游影响 → 确认 → 写入档案。

   例子：
   - *添加新纠纷类型：*「`/client-intake` 会把该类型的接待路由到新模板。`/draft` `/memo` `/client-letter` 用该类型的提示。`/research-start` 会加入对应检索词与法规源。」
   - *监督模式从轻监督 → 正式队列：*「`/supervisor-review-queue` 启用 —— 学生产出会落到那里等你签字才放行。」
   - *新学期滚动：*「我会归档上学期的活跃案件，把你标为继续的转移过来，并提示下一届学生走 `/ramp`。」

5. **收尾。**

   > 完成。下一次输出将反映改动。还要改什么吗？随时 `/legal-clinic-cn:customize`。

## 护栏

- **不删除章节。** 用户想「去掉」某纠纷类型时，提议标 `[已归档]` 并解释：归档保留案件历史访问但把该类型从 `/client-intake` 路由中隐藏。
- **标记内部不一致。** 改动会让档案自相矛盾（正式队列 + 轻监督备注；启用类型 + 无办案地规则）时，标出这处紧张。
- **标记护栏退化。** 以下为承重项，不应删除：`/draft` 的「非终稿」框架、面向受援人产出的通俗语言标准、`/client-intake` 的「不决定是否受理」、`/client-letter` 的「不给实质咨询」、`/memo` 的「骨架而非分析」框架；**学生行为底线 4 条硬约束**（不代理出庭、不承诺结果、不收费、不以律师名义）无论如何**不可移除**。删了会让学生产出无监督送到受援人手上。要改这些，先与用户确认取舍；若用户是学生而非指导老师，建议先请老师定。
- **一次改一件。** 别重问整套访谈。

## 转换决策自检

- **A 级直转：** 5 步骨架（读档 → 展示地图 → 询问 → 改动 → 收尾）、护栏 4 条。
- **B 级大改：** 分组清单换到中式（Clio → 案管系统 / 企业微信 / 钉钉 / 法规检索；immigration/housing/family → 劳动 / 婚姻家事 / 交通事故 / 民间借贷 / 租赁 / 消费 / 刑辩援助）。
- **C 级重写：** 承重护栏清单里加入「学生行为底线 4 条硬约束」并明确**不可移除**（美式版没有等价条目，因为美式假设 licensed intern 制度可覆盖）。
- **D 级新增：** 无。
