# /policy-drafting

1. 加载 `~/.claude/plugins/config/claude-for-legal-cn/employment-legal-cn/CLAUDE.md` → 用工地域足迹、员工手册位置。
2. 用下述工作流。
3. 起草核心制度。为足迹内每个用工地检查所需的地方变体。
4. 输出：核心制度 + 地方补充 + 民主程序 + 公示告知计划。标记法律正在变动的地方。

## 目的

一份对广东合适的制度可能对北京不合适（或不必要）。本技能起草核心制度并为足迹要求不同规则的用工地生成地方补充。**关键：** 制度只有经过民主程序 + 公示告知才能作为管理和解除依据（《劳动合同法》第 4 条）——起草完不落地程序，等于没有制度。

## 加载上下文

`~/.claude/plugins/config/claude-for-legal-cn/employment-legal-cn/CLAUDE.md` → 用工地域足迹、员工手册位置和格式。

## 工作流

### 第 1 步：范围界定

- 制度是关于什么的？（远程办公、产假、社交媒体使用、绩效管理等）
- 为什么现在？（法律要求、事件、扩张、注意到的缺口）
- 适用于谁？（全体员工、特定岗位、特定地区）

### 第 2 步：地方差异扫描

对足迹内每个省市，检查：这个用工地对此主题是否有具体的地方规则？

**常见有地方差异的主题：**

| 主题 | 差异 |
|---|---|
| 产假 | 各省差异（北京 98+60=158、广东 98+80=178、浙江/西藏更长）；难产/多胞胎另加 |
| 陪产假/护理假 | 各省 7-30 天不等 |
| 育儿假 | 三孩政策后多地新增，各省差异 |
| 病假工资 | 上海、北京、广东各有规则，一般不低于最低工资 80% |
| 高温津贴 | 发放月份、金额各地不同 |
| 年假 | 国家统一（1/10/20 年分档），无地方差异 |
| 加班审批与限额 | 国家规则统一（第 41 条：一般每日不超过 1 小时，特殊原因每日不超过 3 小时，每月不超过 36 小时），审批备案地方要求略有不同 |
| 特殊工时审批 | 综合/不定时工时由劳动行政部门审批，各地口径细节不同 |
| 未成年工/劳务派遣 | 派遣三性、10% 比例国家统一，各地执法尺度不同 |
| 竞业限制补偿 | 各地不同（多数 30%，无约定按 30% 支持） |

若主题无地方差异（着装规范等），跳过此步。

### 第 3 步：起草核心制度

一份。到处适用。清晰易读——员工不用律师就能懂。

结构：
- 目的（一句——为什么有这份制度）
- 范围（适用于谁）
- 规则（要求什么/允许什么/禁止什么）
- 流程（如何申请、谁批准、违反了怎么办）
- 咨询（谁问）

避免：「兹」「特此」、嵌套例外。这是员工手册制度，不是合同。

### 第 4 步：地方补充

对规则不同的每个用工地，一份补充：

```markdown
### [省市] 补充

用工在[省市]的员工，除核心制度外还适用以下：

- [具体差异]
- [有帮助时引用地方规定]
```

补充要紧凑。只写不同的——不重复核心内容。

### 第 5 步：民主程序 + 公示告知计划（**必须**）

《劳动合同法》第 4 条：用人单位在制定、修改或者决定直接涉及劳动者切身利益的规章制度或者重大事项时，应当经**职工代表大会或者全体职工讨论**，提出方案和意见，与**工会或者职工代表**平等协商确定。规章制度应当**公示，或者告知劳动者**。

**民主程序动作清单：**
- [ ] 制度草案说明（为什么改、影响什么）
- [ ] 提交职工代表大会 / 全体职工讨论（大会/视频会议/邮件征询）
- [ ] 收集反馈并留档
- [ ] 与工会/职工代表平等协商（无工会的选举职工代表）
- [ ] 会议纪要签字留档

**公示告知动作清单：**
- [ ] 内部平台/OA 系统公示
- [ ] 员工签字确认（签收单/电子确认）——**这是关键**，仲裁/诉讼中要证明「已告知」
- [ ] 新员工入职培训纳入
- [ ] 存档保存

未走民主程序或未公示告知的制度，仲裁/诉讼中不能作为解除或处分依据——直接影响解除合法性。

### 第 6 步：交叉核对

- 这份制度与手册中已有内容冲突吗？
- 承诺的比公司打算兑现的多吗？（制度对公司有约束力——法院会按制度追究雇主。）
- 是否降低了旧版本的员工利益？降低利益的调整同样需要民主程序，且实践中可能被视为对现有员工的不利变更。

## 输出

```markdown
# [制度名]

## 核心制度

[完整文本]

## 地方补充

### [省市 1]
[补充]

### [省市 2]
[补充]

---

## 民主程序 + 公示告知落地计划

**民主程序：**
- [ ] [具体步骤，附时间]

**公示告知：**
- [ ] [具体步骤，附时间]

**签字确认收集：**
- [ ] [方式、平台、存档位置]

---

## 起草说明（内部——插入手册前删除）

- **地方扫描：** [检查过哪些省市，哪些有差异]
- **与现有手册的冲突：** [无 | 列表]
- **法律当前在变的：** [任何在变动中的省市规则]
- **审议周期：** [何时复审——年度或 X 发生时]
```

> **草稿，不是生效制度。** 这是供律师复核的起草辅助，不是可以发布的制度。发布员工手册制度有法律后果——它对公司有合同性约束力，工资、休假、给付制度会被法院严格解读。**未完成民主程序 + 公示告知的制度不能作为解除或处分依据。** 由具备中国劳动法执业资格的律师复核、按需修改并承担专业责任，然后再落地。不要发布或分发未复核的草稿。

## 交接

到 handbook-updates 技能：制度获批时，它对当前手册作差异比对并标记什么变了。

## 本技能不做的事

- 批准制度。它起草；由人批准。
- 落地制度。向员工传达是 HR 工作流。
- 代替民主程序——它规划步骤，程序本身要真实走。
- 覆盖地球上每个法域——只覆盖足迹内的。若足迹扩展，重跑。
