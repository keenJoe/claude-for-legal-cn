# /ip-clause-review

按 `~/.claude/plugins/config/claude-for-legal-cn/ip-legal-cn/CLAUDE.md` 执业档案审查协议中的IP条款。标记转让缺口、权属模糊、许可范围问题与IP保证/赔偿问题。产生带按风险优先级的逐条款发现的备忘录，附建议修订语言（如适用）。

## 指令

1. **加载 `~/.claude/plugins/config/claude-for-legal-cn/ip-legal-cn/CLAUDE.md`。** 存在占位符时停下提示："先运行 `/ip-legal-cn:cold-start-interview`——我需要先学你执业档案才能对其审IP条款"

2. **获取协议：** 从文件路径、Drive链接或粘贴文本。如无提供则问

3. **走下方工作流。** 特别：
   - 确定协议类型与公司在IP上的一侧（授予/接收/双方）。**侧问题按文档，非一次性设置答案**
   - 如协议是劳动、顾问、项目、承揽等应受让方IP的文档，**先跑转让缺口检查**
   - 产生按风险优先级的逐条款发现
   - 检查条款间一致性，非仅逐条款
   - 说明法域含义（**中国法特有：** 职务作品/职务发明权属规则、软件著作权登记效力、专利权归属特别约定优先原则）

4. **按下方模板输出备忘录**——工作成果头部先、底线、转让缺口检查、按严重性条款、一致性标记、法域说明、审批路由

5. **尊重决策立场。** 条款可两方向解读IP分配时，标记律师审并浮现两面因素。**不静默决定主观分配问题**

## 目的

读协议中IP条款并告诉律师每一条做什么、如何偏离市场或团队标准立场、风险是什么、（适用时）具体提议修订。**目标是律师一次可行动的备忘录**

**大多数协议最高风险条款是IP权属与转让。** 事后难修。**在劳动或顾问协议上未取得干净转让**会在并购尽调、融资与诉讼中浮现，有时协议签订多年后。**应有转让的文档中转让语言弱或缺失时，在备忘录顶部醒目标记**——非埋在诸多条目之一

## 先决条件：加载执业档案

**读协议前**读 `~/.claude/plugins/config/claude-for-legal-cn/ip-legal-cn/CLAUDE.md`。若缺失或含占位符停下跑 `/ip-legal-cn:cold-start-interview`。执业档案告诉你：

- **法域足迹**——影响著作权人身权可否放弃、职务作品/职务发明如何处理、专利/著作权约定优先原则
- 谁批准偏离与在什么严重性
- 输出前置的工作成果头部

## 工作流

### 第1步：定位

快读整份协议。回答：

| 问题 | 答案 |
|---|---|
| 什么样协议？ | 劳动 / 顾问或项目 / 供应商框架 / 入许可 / 出许可 / 合作或联合开发 / 和解 / 收购或资产购买 / 其他 |
| 我们在IP上是哪一侧？ | 授予权利或接收 / 转让IP或获取 / 许可人或被许可人 |
| 对方是谁？ | 名，与成熟度——个人、创业公司、大公司、上市公司 |
| **对方主体核对：** | **通过企查查/天眼查核对统一社会信用代码、法定代表人、注册地** |
| 是否有对价专门流向IP？ | 工资、费用、许可费、预付、股权、无 |
| 适用法律与管辖 | 说什么——我们执业档案标该法域为升级/绝不吗？ |

**侧问题按文档，非一次性设置答案。** 公司法务同一天审劳动协议在"接收"侧；审出许可在"授予"侧。立场倒置

侧模糊时（双方贡献双方接收权利的合作协议、有流通IP的转售协议）问：

> [公司]在此协议IP上是哪一侧？授予权利、接收权利还是双方？若双方，我将分别审每方向

### 第2步：转让缺口检查（最高优先级）

协议是劳动协议、顾问协议、项目合同、承揽合同或应受让方在工作成果中IP的其他内容——**先检查转让语言**

**中国法特殊性——权属规则先看法定：**

**著作权（著作权法第18条 职务作品）：**
- **一般职务作品**：作者享有著作权，但**法人或者非法人组织有权在其业务范围内优先使用**（自作品完成之日起2年内未经单位同意，作者不得许可第三人以与单位使用的相同方式使用该作品）
- **特殊职务作品**（作者享有署名权，其他权利由法人或者非法人组织享有）：
  - 主要利用法人或者非法人组织的物质技术条件创作，并由法人或者非法人组织承担责任的工程设计图、产品设计图、地图、示意图、计算机软件等职务作品
  - 报社、期刊社、通讯社、广播电台、电视台的工作人员创作的职务作品
  - 法律、行政法规规定或者合同约定著作权由法人或者非法人组织享有的职务作品
- **委托作品**（第19条）：**约定优先**；无约定属于**受托人**

**专利（专利法第6条 职务发明）：**
- **职务发明**（执行本单位任务或者主要利用本单位物质技术条件所完成的）—— 申请权属于**单位**；单位应给予合理奖励与报酬（第15条+实施细则第76-77条）
- **非职务发明**（除职务发明以外）—— 申请权属于**发明人或者设计人**
- **约定优先原则**（第6条第3款）：**利用本单位的物质技术条件所完成的发明创造**，单位与发明人或者设计人订有合同，对申请专利的权利和专利权的归属作出约定的，**从其约定**——这个"约定优先"是中国法特色

**软件著作权（计算机软件保护条例第13/14条）：**
- 类似专利职务发明——**执行本单位任务开发或主要利用本单位物质技术条件开发的软件著作权属于单位**

看：

- **明确转让声明**——**"XXX将以下IP转让给公司"或"由XXX创作的作品的著作权归公司所有"**。**中国无美国"present-tense assignment"（hereby assigns）与"agrees to assign"区分**——但**明确的转让+具体范围+对价**很重要
- **范围**——覆盖在委托期间创作的所有IP，还是仅与公司业务相关的IP，或仅用公司资源创作的IP？**中国实务：** 明确"工作范围内"或"利用公司物质技术条件"是关键
- **人身权（署名权/修改权/保护作品完整权）：** **著作权法第10条：** 著作人身权原则**不可转让**。但可以约定不行使或授权他人行使。**中国著作人身权保护比美国更强**（美国仅VARA对视觉艺术有限）
- **进一步保证条款** —— 对方同意签署完成转让所需的任何其他文件（**中国实务重要——如需办理著作权/专利权变更登记**）
- **在先IP保留（Background IP）** —— 对方从转让中排除什么，清单是具体还是开放？
- **奖励与报酬约定** —— **专利法第15条+实施细则第76-77条**规定单位对职务发明的奖励与报酬。**书面约定优于法定标准**——建议明确书面

以上任何缺失或弱时，在备忘录顶部标🔴或🟠严重性附具体修订

```markdown
## ⚠️ 转让缺口

**第[X]条**转让工作成果IP，但：[具体问题——如"没有明确职务作品/职务发明书面约定，需依赖法定推定"，或"人身权（署名权）未约定不行使，可能对未来使用产生障碍"，或"未提供在先IP排除清单，对方有既有平台IP"]

**风险：** 这是在并购尽调中多年后浮现的缺口。对方（或继任者）可能对我们以为拥有的工作成果有残余权利。**特别中国实务：** 无书面约定时法定推定适用——**权属可能不匹配预期**

**建议修订：**
> "[具体替换语言]"

**升级：** 按 `~/.claude/plugins/config/claude-for-legal-cn/ip-legal-cn/CLAUDE.md`，转让范围缺口升级到[审批人]
```

> **转让可以传达AI生成内容吗？** 中国北京互联网法院"春风十里"案（AI生成图片具备独创性可享著作权）与近期案例暗示**AI辅助生成作品可能受著作权保护，但完全AI生成无人类独创性贡献的作品可能不受保护**——**边界仍在演变**。若承包商用AI做大部分交付物，那些部分的著作权状态不确定——**转让条款只能传达存在的权利**
>
> 检查：协议有AI使用披露义务吗？关于AI在交付物中角色的陈述？识别哪些部分是AI辅助vs人工创作的机制？
>
> 若缺失且AI辅助创作可预见（顾问、开发、内容创作、设计）：🟠 高。"转让条款起草良好但无AI使用披露。AI生成内容著作权状态不确定，无披露义务你不会知道哪些部分受影响。加AI使用陈述与披露义务。" `[审核——AI生成作品著作权状态在演变领域；对照当前著作权行政管理部门指引与司法判例核验]`

> **AI辅助发明人身份。** 中国专利实务：**发明人必须是自然人**（专利法实施细则第14条）。**AI工具本身不能是发明人**，但AI辅助的技术方案：
>
> - 若人类贡献创造性贡献 → 人类是发明人
> - 若完全AI生成无实质人类创造性 → 权属存疑
>
> 检查：协议有AI使用陈述吗？AI贡献时确定发明人身份的流程？关于发明过程中AI使用的披露义务？
>
> 若缺失：标记。"专利转让无AI使用陈述。若AI工具贡献发明构思，发明人身份判定复杂，错误归属专利可能被无效。加AI使用陈述与发明人身份协议"

### 第3步：逐条款审查

对每个IP相关条款产生一块。要看的条款：

- **权属/职务作品/职务发明** —— 谁拥有协议下创作的
- **交付物权属** —— 与转让不同；常述委托产出
- **改进与派生作品** —— 谁拥有对在先IP的改进，谁拥有派生作品
- **在先IP与前景IP** —— 协议是否分别定义在先IP与新创IP，并将在先IP许可到所需程度？
- **许可授予** —— 范围、独占、地域、使用领域、可分许可、期限、终止触发、许可费或费用结构
- **IP保证** —— 不侵犯第三方权利、有权授予、原创作品
- **IP赔偿** —— 范围、上限、程序、例外（用户修改、组合、未授权使用）。**中国民法典第584/585条违约金调减规则+第506条免责条款无效边界**
- **著作人身权**（**著作权法第10条**：署名权、修改权、保护作品完整权原则不可转让）——**约定不行使或授权行使的处理**
- **开源陈述** —— 关于交付物中嵌入的与未嵌入的OSS的陈述
- **商标使用** —— 对使用对方商标的任何授予或限制；品牌指南；许可人质量控制
- **保密/商业秘密** —— 商业秘密材料处理、相应保密措施（反法第9条）、返还或销毁、期限后义务
- **竞业限制/保密协议关联**（**劳动合同法第24条：** 高管/高技+2年上限+经济补偿）——**注意区分：竞业限制针对劳动者受劳动合同法约束；商业限制针对交易对方受民法典与反垄断法约束**

对每个存在条款产生：

```markdown
### [第X.X条]：[条款名]

**说什么：** [平白英文摘要，一两句]

**市场是什么（对本协议类型、本侧、本法域）：** [简要参考点]

**风险：** 🔴 关键 | 🟠 高 | 🟡 中 | 🟢 低

**为什么重要：** [一两句——若保留业务哪里出错]

**建议修订（如需要）：**
> "[具体替换语言]"

**决策判定：** [不确定条款是否达到预期IP分配时，标记律师审并说明两面因素。不静默决定主观分配问题]
```

**严重性校准：**

| 级别 | 意义 |
|---|---|
| 🔴 关键 | 不修不签。应有转让文档转让缺口。本应窄的无限许可。本应非独占的独占授予。**著作人身权未约定不行使可能造成障碍** |
| 🟠 高 | 强推；若不动升级。范围模糊、缺进一步保证、赔偿窄。**AI使用无披露义务** |
| 🟡 中 | 首轮推；若最后开放项接受。**风格但不精确语言、存续期短于标准** |
| 🟢 低 | 记录，不花资本。**不改变分配的风格偏差** |

### 第4步：跨条款一致性

**IP条款作为系统失败。** 检查：

- **许可授予是否匹配被许可的范围？**（对交付物"使用"的许可比"使用、修改与创建派生作品"的许可窄）
- **保证是否覆盖授予涵盖的一切？**（限于专利的不侵权保证，在也覆盖著作权与商业秘密的许可中留下缺口）
- **赔偿是否覆盖保证承诺的？**（无赔偿的保证是无救济的承诺）
- **终止是否收回许可？**（还是付清许可存续终止？任一可辩——问题是是否匹配意图）
- **本协议与任何相关SOW、订单表或相关补充协议的IP分配一致？** 标记冲突

**中国法特殊性检查：**
- **民法典第508条：** 合同订立时未明确的以合同履行做补充解释——避免留白
- **民法典第509条：** 合同履行原则——按约定全面履行、诚实信用、协助
- **著作权法第26条：** 许可使用与转让合同应当以书面形式订立
- **专利法第10条：** 专利权的转让与专利实施许可合同应当采取书面形式，并向国务院专利行政部门登记（转让还需公告后生效）
- **软件著作权登记：** 独占许可、专有许可、转让合同的备案（虽非生效要件但为证据）

### 第5步：法域说明

IP规则法域特定的方式改变结果。协议涉及以下任何时标记：

- **人身权** —— **中国著作权法第10条人身权（发表权、署名权、修改权、保护作品完整权）原则不可转让**。可以约定不行使或授权他人行使。**大陆法系传统——比美国VARA更强**
- **职务作品** —— **中国著作权法第18条**双轨制（一般职务作品vs特殊职务作品——见上）
- **职务发明** —— **中国专利法第6条**（约定优先原则+奖励与报酬法定标准）
- **软件著作权** —— **计算机软件保护条例第13条**（职务开发规则类似专利）
- **默示许可** —— **中国司法实践承认默示许可较窄**——书面约定优先，无约定时按公平原则、诚实信用与交易习惯（民法典第509条）
- **专利赔偿排除** —— 组合、修改与用户提供被诉功能是中国实务标准排除；与欧盟专利与UPC互动仍在发展
- **涉外/涉台港澳** —— **中华人民共和国涉外民事关系法律适用法**：知识产权归属与内容适用被请求保护地法律；侵权责任适用被请求保护地法律或者当事人协议选择的适用地法律；涉台港澳IP有专门制度

说明协议适用什么法域，与我们执业档案标该法域为**标准、升级或绝不**

## 修订颗粒度

**在最小可能颗粒度编辑。** 修订是**谈判产物**，非重写。整条款替换发信号"我们扔掉你的起草"——它进攻性、迫使对方重读整个条款、并丢掉对方起草的还可以的部分。**手术性修订**——删除一个词、插入一个短语、重构一个子条款——发信号"我们有具体要求"且更快读、理解与接受

默认到达到playbook立场的最小编辑：
- 先替换**词**再短语。（"十二（12）"→"二十四（24）"）
- 先替换**短语**再句子。（"由买方付"→"由买方支付并到期"）
- 先重构**子条款**再替换句子。（加"(a)"与"(b)"分割复合条件）
- 先替换**句子**再替换条款
- 仅当对方版本远离你立场手术编辑比新起草难读时才替换**整条款**——你这么做时在交接中说："我们替换了第8.2条而非标记它，因变更范围大。乐于向你解释增量"

疑问时更小。收到手术修订的客户信任你仔细读了。收到批量替换的客户怀疑你是否读了

## 转换决策

**级别：B（大改）** —— 保留审查工作流架构（定位/转让缺口/逐条款/一致性/法域）、严重性四级（🔴🟠🟡🟢）、修订颗粒度、事项工作区、决策立场：

- 权属doctrine完全替换：US 17 U.S.C. § 101 work-for-hire → 中国著作权法第18条职务作品双轨制（一般vs特殊）+第19条委托作品约定优先+计算机软件保护条例第13条
- 专利权属：US assignment doctrine → 专利法第6条职务发明+第15条奖励+实施细则第76-77条法定报酬标准+**中国特色约定优先原则（利用单位物质技术条件所完成的可以合同约定归属）**
- 著作人身权：US VARA限于视觉艺术 → 中国著作权法第10条大陆法系人身权（发表/署名/修改/保护作品完整权）原则不可转让+可约定不行使
- 转让语言：US "hereby assigns" vs "agrees to assign" → 中国无此doctrine区分；重点在明确的转让+具体范围+对价+进一步保证（如登记）
- 许可默示：US common law implied license → 中国司法实践承认较窄+民法典第509条公平原则/诚实信用/交易习惯
- 保证/赔偿：US uncapped/capped → 民法典第506条免责条款无效边界+第584-585条违约金调减规则
- 涉外：US foreign associate review → 中华人民共和国涉外民事关系法律适用法（IP归属与内容适用被请求保护地法律）+涉台港澳专门制度
- AI相关新增：AI生成内容著作权演变（春风十里案）、AI辅助发明人身份（专利法实施细则第14条自然人要求）
- 数据库：US Westlaw → 北大法宝/威科先行/国家法律法规数据库
- 保留：转让缺口优先检查、修订颗粒度小到大、决策立场、事项工作区
- 新增：中国合同法要点——著作权法第26条书面形式、专利法第10条专利转让书面+登记（转让公告后生效）、软著登记备案
- 新增：企查查/天眼查对方核对——中国实务必需
