# 指导老师审核队列（可选）

## 目的

有的诊所要正式关卡：学生起草、老师审核、成果放行。有的觉得那太生硬 —— 通过讨论会和一对一监督，不用队列。

**本 skill 仅在 `~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/CLAUDE.md` → 监督模式为「正式审核队列」时启用。** 其它模式下休眠 —— cold-start 让老师从三选一里选，这是其中之一。

诊所要不要正式审核工作流，是一个真正开放的问题。取决于学生经验、案件量、老师既有的监督方式。老师在 setup 里定，之后可改。

## 加载上下文

`~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/CLAUDE.md` → 监督模式。若**不是**「正式审核队列」，回复：「诊所设置为 [可配置标记/轻监督] 监督 —— 无正式队列。[老师] 通过 [诊所既有结构] 审核。要切换到正式队列，编辑 CLAUDE.md → 监督模式。」

若正式队列启用 → 读标记触发条件继续。

## 队列

存于 `references/review-queue.yaml`。每条：

```yaml
- id: Q-001
  type: "draft"  # intake | draft | memo | status | client-letter
  case_client: "[案件受援人 name 或 ID]"
  student: "[学生 name]"
  submitted: [时间戳]
  flags:
    - rule: "提交仲裁委/法院"
      detail: "劳动仲裁答辩状 —— 一律入队"
  content_path: "[文档路径]"
  status: "pending"  # pending | approved | edited-approved | returned
```

## 模式

### 待审

```markdown
## 审核队列 —— [日期]

**待审：** [N] | **最久：** [N] 小时

### 🔴 期限敏感
| ID | 类型 | 案件受援人 | 学生 | 为何标 | 等待 |
|---|---|---|---|---|---|

### 标准
[同表]

### 按学生
[分布 —— 发现模式：谁入队频繁、谁可能需要 check-in]
```

### 审一项

显示完整内容 + 为何标 + 学生的注。

### 批准 / 改后批准 / 退回

- **批准：** 状态 → approved，通知学生，留痕。
- **改后批准：** 老师内联改，批准版是改后版，原版保存在日志里让学生看到 diff（教学时刻）。
- **退回：** 带备注。学生改后重提。

## 留痕

每次动作留痕。批准日志是**诊所记录**，说明**指导老师**审阅了学生工作，然后才发到受援人或提交法院/仲裁委。这对诊所合规与学生评估都重要。

## 教学信号

队列本身是数据。退回模式（「某学生总漏送达要求」）是辅导契机。改动模式（「大家的律师函都太长」`[注：律师函须由律师签发，学生仅辅助起草]`）是下学期 `/ramp` 的更新点。

## 本 skill 不做的事

- **老师没选它就不跑。** 三种监督模式之一，不是唯一。
- **不自动批准。** 老师批。
- **不替代诊所既有监督结构。** 是对**工作成果**的关卡，不替代讨论会、一对一、看着学生做。
- **不批准需律师签发的对外文件。** 律师函、拟提交法院/仲裁委由律师身份签发的文书须由指派/合作律师签发；老师批准的是「可交由律师定稿签发」，不是「可直接以学生名义发出」。

## 转换决策自检

- **A 级直转：** 队列结构、三档模式（批准 / 改后批准 / 退回）、默认待审展示、教学信号机制。
- **B 级大改：** 触发标记例子改为中式（提交法院/仲裁委、劳动仲裁答辩期、涉家暴、涉未成年人）；退回备注示例改为中式（「劳动仲裁答辩期 15 日 —— 请与仲裁委立案通知上的日期核对」）。
- **C 级重写：** 「Approval logs are clinic records」段替换为「指导老师审阅是诊所记录」，不再提 licensed attorney 制度（美式）；改由**指导老师 + 律师身份签发**双层责任。
- **D 级新增：** 「不批准需律师签发的对外文件」显式列入 —— 关卡通过≠可以学生名义发出；律师函、法院/仲裁委提交材料要区分。
