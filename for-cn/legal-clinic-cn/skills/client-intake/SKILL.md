# 案件接待

## 目的

接待是诊所最大的瓶颈之一。学生可能花 45 分钟面谈、再花一小时写记录、再花时间识别问题；等候的人越排越多。

本 skill 结构化对话、产出记录、跨类型识别问题、标记冲突 —— 让学生把时间放在分析上，而不是抄写上。

**它不做的事：决定要不要接这个案。** 那是学生的分析、老师的判断。Claude 加速信息收集与结构化，不做「律师工作」。

## 加载上下文

`~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/CLAUDE.md` → 纠纷类型、接待模板（若按类型分开）、监督模式、办案地、标记触发条件。

## 读老师指引

检查 `~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/guides/<纠纷类型>.md`。若有，用它的问题、红旗、适合本诊所标准替代下面默认。若无，用默认，并在摘要末尾注：「本次为通用接待 —— 老师可用 `/legal-clinic-cn:build-guide` 为诊所类型定制问题。」

接待在纠纷类型路由前就开始时（下方工作流第 1 步），路由完成后重查指引路径。

## 工作流

### 第 1 步：纠纷类型路由

这次接待起步在哪类纠纷？受援人可能不知道 —— 他/她知道自己的问题，不知法律分类。

> 「先说说是什么事？今天来诊所因为什么？」

从回答路由到对应接待模板。若诊所办多类型且问题跨类型（劳动咨询里提到婚姻，交通事故里提到未成年子女），把相关类型都记 —— 跨类型识别是特性不是 bug。

### 第 2 步：按纠纷类型接待

各纠纷类型问题不同。用档案里的对应模板。若无，用下方默认：

**劳动人事争议：**
- 用人单位名称（营业执照全称），是否与实际发放工资单位一致（涉劳务派遣、外包时经常错位）
- 岗位、入职时间、离职时间、月工资构成（基本+绩效+补贴）
- 是否签书面劳动合同（未签满一个月不满一年，二倍工资，劳动合同法第 82 条）
- 社保 / 公积金是否缴纳、缴纳基数与实发工资是否一致
- 争议起因：拖欠工资 / 违法辞退 / 未缴社保 / 工伤 / 加班费 / 竞业限制
- 已有证据：劳动合同、工资流水、考勤、微信/邮件、社保记录、录音、证人
- 时效紧迫：**仲裁时效 1 年**（自当事人知道或应当知道权利被侵害之日；劳动关系存续期间因拖欠劳动报酬的，不受 1 年限制，终止后 1 年内提出）—— 劳动争议**仲裁前置**
- 是否已申请仲裁 / 已收到裁决书 / 是否已在诉讼中

**婚姻家事：**
- 关系与争议焦点（离婚 / 抚养费 / 探望权 / 财产分割 / 赡养）
- 是否有子女：年龄、当前照顾情况
- **人身安全：** 是否有暴力、威胁、恐惧（谨慎处理 —— 见跨类型红旗）—— 涉家暴的按人身安全保护令处理
- 现有生效裁判 / 调解协议
- 时效紧迫：起诉状递交时间点、开庭日期、离婚冷静期 30 日（民法典第 1077 条 —— 协议离婚）

**交通事故 / 人身损害：**
- 事故时间、地点、事故认定书结论、责任划分
- 车辆保险情况（交强险 + 商业三者险，投保人 / 被保险人）
- 伤情：门诊 / 住院、伤残鉴定情况、后续治疗预期
- 已支付医疗费、误工证明（收入证明 + 完税凭证）
- 时效紧迫：**诉讼时效 3 年**（民法典第 188 条，从知道或应当知道权利被侵害以及义务人之日）

**民间借贷：**
- 借款金额、借款日、约定还款日、约定利率
- 借条 / 欠条内容，是否有转账凭证（银行流水、微信/支付宝转账记录）
- 已还本金 / 利息金额与凭证
- 借贷双方关系（亲友、同事、陌生人、经营性借贷）
- **利率上限：** 一年期 LPR 的 4 倍（最高法民间借贷司法解释，2020 修正），合同成立时的 LPR 为准
- 时效紧迫：**诉讼时效 3 年**；未约定还款期限的从债权人主张之日起算

**房屋租赁 / 物业：**
- 合同期限、月租金、押金金额与去向
- 争议起因：租金拖欠 / 押金退还 / 提前解约 / 房屋质量 / 物业费
- 已有证据：租赁合同、押金收据、转账记录、房屋照片、维修记录、微信沟通
- 时效紧迫：搬离时间、法院开庭 / 送达情况

**消费者权益：**
- 消费类型（商品 / 服务）、经营者名称与地址
- 已支付金额、消费凭证（发票、收据、订单截图、聊天记录）
- 损害事实：欺诈 / 质量问题 / 人身损害 / 未如约提供
- **退一赔三：** 消费者权益保护法第 55 条；食品另有十倍赔偿（食品安全法）
- 已通过什么渠道维权（12315 投诉、平台客服、律师函）

**刑事辩护援助 / 值班律师：**
- **谨慎处理：** 学生不能会见在押人员、不能出庭。以下仅做辅助信息收集与向合作律师转介。
- 涉嫌罪名、所处阶段（侦查 / 审查起诉 / 审判）
- 强制措施（取保候审 / 监视居住 / 刑拘 / 逮捕）、羁押场所
- 是否已委托辩护人 / 是否已指派法律援助律师（刑诉法第 35 条应当通知辩护情形）
- 是否涉认罪认罚从宽（值班律师法律帮助与见证具结，刑诉法第 36 条）
- 家属联系方式与经济状况（法律援助经济困难审查）

### 第 3 步：跨类型问题识别

按纠纷类型模板问的同时，留意本类型之外的问题：

| 受援人说 | 也标出 |
|---|---|
| 「我怕丢工作 / 老板知道我怀孕」 | 劳动 —— 即便在婚姻家事接待里，涉孕期辞退限制（劳动合同法第 42 条） |
| 「他/她打我 / 威胁我」 | 家暴 / 人身安全保护令（反家庭暴力法）—— 即便在民间借贷接待里 |
| 「因为伤没法上班」 | 可能的工伤 + 人身损害赔偿 / 误工费 |
| 「他们把工资从卡上扣走」 | 可能的行政强制 / 强制执行相关（若已有生效裁判） |
| 「房东说要报警 / 找我单位」 | 房屋租赁 + 可能的骚扰 / 借款人 vs. 债权人权益 |
| 「对方是国企 / 上市公司 / 大平台」 | 谈判空间与地方保护差异，影响策略 |
| 「用人单位是外资 / 香港公司 / 台商」 | 跨法域识别触发 —— 涉外劳动争议管辖与法律适用规则专门，标记升级 |
| 「受援人是未成年人 / 老年人 / 残疾人」 | 特殊主体，法律援助优先 + 需专门保密与陪同处理 |

每一项都记入摘要。诊所是自办、转介、还是两者，是老师判断。学生应当看到。

### 第 4 步：利益冲突标记

按档案里的冲突检查流程。至少：

- 对方名称：诊所是否代理过 / 现代理？
- 相关方：还有谁可能与学生或诊所存在冲突（师生关系、亲属关系）？
- 立场冲突：本案主张是否与诊所另一在办案件相冲突？
- **高校诊所特有：** 对方是否为依托高校本身、附属单位、老师本人的关联主体？—— 若是，标记升级到指导老师复议是否移交给校外法律援助中心

标记供老师复核。**别解决冲突 —— 暴露它。**

### 第 5 步：分诊分类

不是受理决定 —— 是分诊输入：

| 分类 | 含义 |
|---|---|
| **紧急** | 期限在几日内、有人身安全风险、有不可逆损害将至 |
| **时效敏感** | 期限在几周内（诉讼时效将届、开庭在即、送达答辩期），损害在发生但非立即不可逆 |
| **标准** | 无紧迫期限，可按队列正常处理 |
| **可能超出范围** | 议题超出诊所办理类型 —— 标记以评估转介 |

### 第 6 步：监督标记检查

按档案的监督模式与标记触发条件。若开了正式队列或可配置标记，且有触发信号（时效将届、涉家暴、涉未成年人、涉刑等），记录标记。

### 第 7 步：期限交接 —— 必需交付物

若接待中出现任何时限（答辩期、开庭日、**诉讼时效 / 仲裁时效**、举证期限、上诉期、送达期、通知期、认罪认罚考察期），
**产出一段可复制粘贴的 `/legal-clinic-cn:deadlines --add ...` 块作为接待输出的一部分**。这是必需交付物，不是建议 ——
接待识别期限，学生不应再抄一遍。

每个期限一段围栏代码，字段从接待预填：

```
/legal-clinic-cn:deadlines --add
  case=[案件 slug 或 受援人姓氏-关键词]
  type=[response|answer|hearing|statute-of-limitations|arbitration-limitation|evidence|filing|service|notice|appeal|enforcement|other]
  description="[一行简述]"
  due=[待核 —— 学生+老师依触发事件与规则计算]
  source="[触发事件 + 法条/规则来源，例如「劳动合同解除通知于 2026-05-04 送达，劳动争议调解仲裁法第 27 条」]"
  owner=[学生姓名]
  warnings=[14,7,3,1]
```

规则：
- 每个期限一段。不合并。每段都会走 deadlines skill 的预加重复检查。
- 期限须计算的（答辩期、诉讼时效 / 仲裁时效、送达期），`due=` 留 `[待核 —— 学生+老师计算]`。deadlines skill 不替你算；学生和老师算好再更新。
- 触发文书上已有明确日期的（开庭传票上的开庭日、法律文书上的送达日），把日期填入 `due=`。计算得来的（从触发事件数 N 日），留 `[待核]`。
- 接待未出现期限时省略本节 —— 不要凭空造。

## 按纠纷类型的接待模板

模板存于 `references/intake-templates/[类型].md`。cold-start 从老师的接待表填充；若无，用上面默认。

## 本 skill 不做的事

- **不决定是否受理。** 学生分析，老师决定。
- **不解决冲突。** 标记给老师。
- **接待中不给法律意见。** 接待是收集；意见来自分析与老师复核之后。
- **不出终稿。** 摘要是起点 —— 学生读、修正被误录的信息、在此之上做分析。
- **不承诺结果 / 不收费 / 不代理出庭。** 这四条是学生行为底线，无论接待中受援人问什么都要坚持。

## 以决策树收尾

按 CLAUDE.md `## 输出` 的下一步决策树收尾。把选项定制到本 skill 刚产出的内容 —— 5 条默认分支（起草 X、升级、补事实、观察等待、别的）是起点，不是绑死。老师/学生选，Claude 展开。

## 转换决策自检

- **A 级直转：** 工作流 7 步骨架、跨类型问题识别机制、分诊分类（紧急/时效敏感/标准/超出范围）、监督标记检查、输出结构、决策树收尾。
- **B 级大改：** 纠纷类型（美式 immigration/housing/family/consumer → 中式劳动/婚姻家事/交通事故/民间借贷/租赁物业/消费/刑辩援助）；每类的具体询问点全部按中国法重写（劳动合同法第 82 条二倍工资、民法典第 188 条 3 年时效、消保法第 55 条退一赔三、LPR 4 倍利率等）；期限 type 词汇加入 `arbitration-limitation`。
- **C 级重写：** 冲突检查加入「依托高校关联主体」高校诊所特有维度；跨类型标记表按中国常见交叉重写（家暴、涉未成年人、外资企业跨法域）；「Privilege」 → 保密义务与学生行为底线 4 条硬约束；ICE/CBP → 涉外主体路由。
- **D 级新增：** 劳动争议**仲裁前置**在时效敏感项、期限交接段与结论中反复点出（这是与美式最大的程序差异）；刑辩援助 / 值班律师专段（认罪认罚从宽、刑诉法第 35、36 条），并明确学生「不会见、不出庭」；引用「诊所对手是依托高校关联主体」利益冲突特色红旗。
