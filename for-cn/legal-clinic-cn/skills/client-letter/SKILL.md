# 受援人信函：常规通信

## 目的

诊所要发很多常规信函：「你的预约在周二下午 2 点」「请带上你的租赁合同」「我们已经提交了仲裁申请」。本 skill 用模板处理它们，学生不用每周敲同样的字。

**范围：仅常规。** 实质咨询、坏消息、案件策略 —— 走 `/status client` 或面谈，不是模板信函。

## 加载上下文

`~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/CLAUDE.md` → 通俗语言标准、监督模式、诊所联系方式。

## 教学姿态检查

读该纠纷类型的老师指引 `~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/guides/<纠纷类型>.md`。查 `pedagogy_posture`：

- **`guide`（默认）：** 出结构与清单（必备要素、通俗语言目标、按学生行为底线的落款）。让学生起草每段。给反馈（措辞、可读性、必备要素、漏了什么）。学生试过一次才提议填某段。
- **`assist`：** 出信件。标出待学生复核的项。学生改动中学习。
- **`teach`：** 不出信件。请学生起草。给反馈。学生卡住时用引导性提问。两次尝试后才给一段范例，且只给那一段。跟踪对错让老师看到进步。

无指引就用 `guide`。有指引但没设姿态用 `guide`。

无论哪种姿态，输出都包含：「**教学模式：[assist/guide/teach]** —— 由你老师的指引设定。含义：我做了 [X]、学生做了 [Y]。」

## 落款与学生身份披露

按诊所所在地实践规范核对学生署名要求 `[a待核验：本地对高校诊所学生署名的具体规定]`。多数情况下学生须表明**法学院学生 / 诊所志愿者**身份，并注明指导老师。**学生不能以律师名义署名。**
下方模板用通用形式 —— 发出前按你诊所要求调整。

## 信函类型

> **审阅标注放在信函之外。** `[AI 辅助草稿 —— 按插件配置的监督步骤审阅]` 是给学生的提醒，不是信件正文的一部分。放在渲染模板上方（或学生发送前会删掉的抬头），
> 绝不放在围栏代码里的信件正文中。若它出现在给受援人的版本，本 skill 就失败了。

## 发送前

给受援人发信是重大行为。本插件的关卡是档案 `## 监督模式` 里描述的监督流程，配合第 0 部分的角色核验（指导老师）。这道关始终成立：每一封信都要过审再离开诊所。

发送前确认：

1. 草稿已按 `~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/CLAUDE.md` 的监督流程审阅（队列 / 标记 / 轻监督）。
2. 所有内部审阅标注（`[AI 辅助草稿]`、任何 `[核实]` 或 `[缺事实]` 标）都已从对受援人的版本中删除。
3. 落款符合诊所对学生署名的要求；实质咨询、法律意见部分由指导老师或指派 / 合作律师署名，学生不得以律师名义署名。

**这是学生草稿供指导老师审核，不是终稿。** 发出去对受援人有法律后果，可能构成法律咨询或以受援人名义的对外沟通。指派 / 合作律师承担实质法律工作，指导老师审核并签署放行，然后才离开诊所。**未获老师批准不发。**

## 通俗语言检查

按 `~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/CLAUDE.md` 的通俗语言标准。短句。不用书面语「兹」「特此」「系」「诉请」「查」等。可读性目标（默认初中文化程度可读懂）。模板里出现受援人可能不熟的法律术语时第一次出现要解释：「我们已经提交了『答辩状』——那是回应对方主张的正式文件。」

## 监督路由

按 `~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/CLAUDE.md`。常规通信是否触发标记取决于老师选的监督模式：
- **轻监督：** 学生审后发，不入队。
- **可配置标记：** 触发条件时标出「请与指导老师确认再发」。
- **正式队列：** 即使常规信函也入队。

## 本 skill 不做的事

- **不给实质咨询。** 信件若要说「我认为你的案件如何如何」「你应该做什么」，那不是常规 —— 走 `/status client` 或先与指导老师面谈。
- **不发坏消息。** 结案、不利裁决、无法办理 —— 需要思考不是模板。标记给老师。
- **不写给对方 / 法院 / 仲裁委 / 监管的信。** 不同对象、不同 skill（`/draft` 或 `/status court`）。**学生不能以律师名义**给对方或法院发正式函件。
- **不出律师函。** 律师函须由指派 / 合作律师签发。学生只能起草辅助材料。

## 转换决策自检

- **A 级直转：** 三种信函类型（预约 / 材料清单 / 简短进展）骨架、教学姿态检查、审阅标注放在信函外的规则、通俗语言目标、监督路由三档。
- **B 级大改：** 落款完全重写 —— 「Law Student, Certified Legal Intern / Under the supervision of [Supervising Attorney]」→「XX 大学法学院学生·法律援助诊所志愿者 / 指导老师：[姓名]」，明确「学生不能以律师名义」；材料清单例子换成中式（劳动合同、工资流水、解除通知）；简短进展例子换成仲裁委立案、律师函（由指派律师签发）。
- **C 级重写：** 「student practice rule」→ 诊所所在地实践规范 `[a待核验]`；6th grade → 初中文化程度可读懂；禁用词从「pursuant to / heretofore」→「兹 / 特此 / 系 / 诉请」；「Bad news 需 attorney」→「实质与不利消息由指派 / 合作律师承担」。
- **D 级新增：** 「不出律师函」显式列入不做事项，明确律师函须由指派 / 合作律师签发；材料送达方式加入「微信」；`[a待核验]` 标记应用于本地对学生署名的具体规定。
