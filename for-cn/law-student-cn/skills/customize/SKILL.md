# /customize

## 何时运行

用户输入了 `/law-student-cn:customize`。他想改学习档案里的某一项 —— 一门课、学习风格偏好、法考科目 —— 不必重跑整个冷启动访谈，也不必手工去改 YAML。

## 该做什么

1. **读配置。** 读 `~/.claude/plugins/config/claude-for-legal-cn/law-student-cn/CLAUDE.md`。若文件不存在或仍带 `[待填写]` 标记，说：

   > 你还没跑过初始化。先跑 `/law-student-cn:cold-start-interview` —— customize 是用于调整已有档案的。

2. **展示可自定义地图。** 列出档案里的项，分组，每项一行当前值摘要：

   - **学生画像** —— 姓名、学校、年级（本科 / 法硕 / 已毕业备考）、法考目标、参加的诊所或期刊
   - **当前课程** —— 课程名、老师、教学大纲位置、考试形式（闭卷 / 开卷 / 案例分析 / 论文）、课堂互动风格
   - **学习风格** —— 苏格拉底式 vs 讲解式，想被追问多狠，是否允许技能替你写作（默认不允许）
   - **案例研读偏好** —— 格式（裁判要旨 / 争议焦点 / 法院分析 / 代理思路 或简化版）、规则详略、是否含法理讨论、已存的模板
   - **法考备考** —— 阶段（第一轮 / 第二轮 / 冲刺）、卷别（客观题 / 主观题 / 两者）、科目权重、弱项标记、真题 vs 模拟题节奏
   - **样本文件** —— 教材路径、以往大纲、批改过的作业、往年真题、法考真题、教学大纲、论文
   - **学习节奏** —— 单次训练时长、闪卡 Leitner 桶节奏、考试预测频率、课堂预习时间
   - **集成** —— 法规检索 / 案例检索 / 文档存储的状态与回退方式

3. **问他要改什么。**

   > 你想调哪一部分？点一个章节，或直接用你自己的话描述要改什么。

4. **做修改。** 展示当前值，问新值，说明会影响下游哪些技能，确认，写入配置。

   例子：
   - *加一门新课：* 「`/outline-builder` 会为这门课搭一份新大纲。`/flashcards` 会新增一个科目桶。`/cold-call-prep` 在你调用时会问是哪次课、哪个案例。」
   - *学习风格从苏格拉底改讲解式：* 「`/socratic-drill` 不再让你先答题 —— 它会先讲清规则和例子，再考你怎么套用。」
   - *加一个法考科目：* 「`/bar-prep-questions` 会把这科纳入训练轮换。若你标为弱项，权重更高。」

5. **收尾。**

   > 已改。下次输出就会反映这次改动。还有别的要调吗？随时可跑 `/law-student-cn:customize`。

## 护栏

- **绝不删除章节。** 学生想「弃」一门课时，改为标注 `[已归档 —— 保留样本文件]`，并说明闪卡和大纲的行为怎么变。
- **提示内部一致性问题。** 若改动会让档案自相矛盾（如「讲解式」学习风格 + 「最强追问」的苏格拉底设置），提示这个张力。
- **护栏降级要提醒。** `/legal-writing` 和 `/irac-practice` 的「不改写你的写作」规则是承重的 —— 技能的价值在结构反馈，不在代写。若用户要求关掉，先确认他理解本插件不会替他写作业。同理，`/socratic-drill` 的「不给答案」也是承重规则。
- **一次一改。** 别重开整场访谈。

## 什么时候不用 customize

- **新学期整体切换：** 用 `/law-student-cn:cold-start-interview --redo` 更合适（课程、教材、老师、学期目标全变）。
- **只查集成状态：** 用 `/law-start-interview --check-integrations`。
- **改学习计划本身（不是偏好）：** 用 `/law-student-cn:study-plan --update`。

## 转换说明（质量自检）

- **分级：A 级直接转化。** 原技能框架完整保留 —— 读配置、展示可自定义地图、问改什么、做修改、说明下游影响、护栏（不删章节 / 内部一致性 / 护栏降级提醒 / 一次一改）。
- **实体法层替换：** 章节列表按 CN 档案结构替换（法考卷别、案例研读的中国格式、法规检索源为国家法律法规数据库等中国工具，去掉 UBE/state 概念）。
- **命令前缀本地化：** `/law-student:customize` → `/law-student-cn:customize`，配置路径 `claude-for-legal-cn/law-student-cn`。
- **保留「自定义辅导」核心：** 按任务书要求，保留「一次一改，不必重跑访谈」的定位。
- **D 级新增小节：「什么时候不用 customize」** —— 引导到 cold-start-interview --redo / --check-integrations / study-plan --update，便于中文用户区分工具。
