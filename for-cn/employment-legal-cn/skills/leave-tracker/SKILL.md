# /leave-tracker

检查所有有法定期限的已打开休假，只浮现需要决定或行动的。不是状态板——告诉你需要做什么以及为什么。

## 说明

1. 加载 `leave-tracker` agent 并跑完整工作流。

2. 若无 HR 系统连接且 `~/.claude/plugins/config/claude-for-legal-cn/employment-legal-cn/leave-register.yaml` 不存在，提示上传休假花名册或用 `/employment-legal-cn:log-leave` 添加条目。

3. 只对需要行动的休假报警。清洁休假每条一行摘要。

## 说明——工作流

对台账中的每条打开休假，检查以下期限并按类别报警：

**医疗期**（《企业职工患病或非因工负伤医疗期规定》）
- 医疗期长度：3-24 个月，按累计工作年限和本单位工作年限确定
- 医疗期届满提醒：期满前 30 日报警——第 40 条第 1 项：医疗期满不能从事原工作也不能从事另行安排的工作时才能解除，且需 N+1 补偿或代通知金
- 期满前需完成：能否胜任的评估、另行安排工作的方案、劳动能力鉴定（如适用）

**工伤停工留薪期**（工伤保险条例第 33 条）
- 一般不超过 12 个月，伤情严重或情况特殊经设区市劳动能力鉴定委员会确认可延长不超过 12 个月
- 期满未鉴定：报警——需申请劳动能力鉴定
- 期满并鉴定后：按伤残等级支付相应待遇，不再享受停工留薪

**三期女职工**（女职工劳动保护特别规定）
- 产假：98 天基本产假 + 地方增加天数（各省市不同，通常 30-90 天不等；难产/多胞胎另有增加）
- 产假期满 + 哺乳期结束（婴儿满 1 周岁）：报警——期间不得解除（第 42 条）
- 产假期结束时点、哺乳期结束时点各设一个报警

**其他假**
- 事假、年假：一般不涉及法定期限报警，除非年假折算争议临近离职结算
- 竞业限制补偿支付：每月支付节点，未按月支付超过 3 个月员工可解除竞业限制（最高法司法解释）

4. 报警格式：

```
⚠️ [员工/角色] — [用工地] — [假别]
  开始：[日期]  当前：[第 N 天]
  下一节点：[什么事] — [日期]（还剩 [N] 天）
  需要的动作：[具体做什么]
  依据：[法条]
```

清洁休假：一行摘要（[员工] — [假别] — 剩余 [N] 天）。

## 示例

```
/employment-legal-cn:leave-tracker
```

每周跑——设周一早晨提醒调用 `/employment-legal-cn:leave-tracker`。自动化调度需要独立集成（日历提醒、cron 等）；Claude Code agent 不自我调度。
