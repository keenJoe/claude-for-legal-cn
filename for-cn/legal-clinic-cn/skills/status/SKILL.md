# 状态：按对象的案件说明

## 目的

诊所会产生大量状态说明 —— 给受援人、给老师、给合作律师、给法院/仲裁委。同一个案件、同一份事实，完全不同的文档。本 skill 从案卷读事实，按对象产出对的说明。

## 加载上下文

`~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/CLAUDE.md` → 监督模式、通俗语言标准（面向受援人）、办案地。
案卷提供事实。

## 对象模式

### 面向受援人

**读者：** 受援人。多半焦虑。可能不熟法律程序。可读性按档案里的通俗语言标准（默认初中文化程度可读懂）。

**包含：**
- 距上次沟通以来发生了什么
- 下一步是什么、什么时候
- 受援人（如有）要做什么
- 怎么联系诊所

**不包含：**
- 法律分析（不需要 IRAC）
- 案件弱点（除非到了该谈的时刻 —— 那是老师的判断，不是状态说明）
- 术语

*学生用的审阅标注（不是给受援人 —— 发出前去掉）：*
`[AI 辅助草稿 —— 须经学生审阅与按插件配置监督步骤审]`

按诊所对学生署名的要求核实。

```markdown
[受援人] 您好：

给您汇报一下您案件的进展。

**发生了什么：** [大白话。「我们已于 [date] 向劳动人事争议仲裁委员会提交您的仲裁申请书」，不是「我方已按劳动争议调解仲裁法向管辖仲裁委提起劳动仲裁」]

**下一步是：** [是什么、什么时候。「仲裁委将安排开庭时间，通常在立案后 45 日内。收到开庭通知后我们会立刻联系您。」或「我们在等对方的答辩，一般在 [X] 日答辩期内回复。」]

**您要做什么：** [具体明确。或「暂时不用做什么 —— 有需要我们会主动联系您。」]

**联系我们：** [诊所电话、值班时间、学生姓名]

[学生姓名]
[XX 大学]法学院学生·法律援助诊所志愿者
指导老师：[指导老师姓名]
[诊所名称]
```

**发送前：** 发受援人状态说明是重大行为。关卡是档案 `## 监督模式` 里的监督流程，配合第 0 部分角色核验。确认草稿已按监督流程审阅（队列 / 标记 / 轻监督），所有内部审阅标注（`[AI 辅助草稿]`、`[核实]` 等）已从受援人版本删除。

### 内部（给指导老师）

**读者：** 指导老师。懂法律，想知道案件在哪里、学生需要老师做什么。

**包含：**
- 案件所处阶段（立案前、答辩 / 举证阶段、庭前、开庭、裁决后、执行阶段）
- 上次以来做了什么
- 临近事项（期限、开庭）
- 需老师定的点
- 学生自评（进展如何、担忧）

- [做了什么]

## 临近事项

### 面向法院/仲裁委

**读者：** 法官 / 仲裁员 / 书记员。正式。针对法院/仲裁委的要求（法院命令要求的状态说明、开庭前的说明、仲裁委立案后指引下的说明）。

**包含：**
- 案件所处阶段（简明）
- 目前证据 / 待处理事项 / 调解状况
- 待处理事项
- 建议的下一步 / 排期

**格式：** 按本地规则。抬头、当事人称谓、送达证明（若须送达）。

**关键约束：** **学生不代理出庭，也不能以律师名义向法院/仲裁委发送状态说明。** 若须以律师名义签署或提交，由指派/合作律师承担；学生仅辅助起草。

## 监督路由

按 `~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/CLAUDE.md`：
- 面向受援人 → 通常触发（受援人沟通）
- 内部 → 不触发（本来就给老师）
- 面向法院/仲裁委 → 一律触发（提交事项），且**须律师签署**

## 本 skill 不做的事

- **不决定告诉受援人什么。** 尤其是坏消息或案件弱点 —— 那是学生与老师面谈、然后学生与受援人面谈的事。状态说明是**状态**，不是**建议**。
- **不向法院/仲裁委提交任何东西。** 起草文档；老师审；律师签署 / 提交；按诊所流程。
- **不替代学生内部状态里的自评。** 「学生自评」段是学生的思考 —— 草稿可搭结构不能写内容。
- **不以学生名义签发正式对外文件。** 学生**不代理出庭 / 不签发律师函 / 不以律师名义提交**。

## 转换决策自检

- **A 级直转：** 3 种对象模式（受援人 / 内部 / 法院或仲裁委）骨架、通俗语言与内部内容对比、监督路由三档、审阅标注放外部的规则。
- **B 级大改：** 面向受援人示例语言换到中式（劳动仲裁语境）；面向法院部分从「STATUS REPORT + Caption + Certificate of Service」→「案件情况说明 + 抬头 + 送达证明」；stage 词汇从「pre-filing / answer filed / discovery / motion pending」→「立案前 / 已立案 / 答辩期 / 举证期 / 已开庭 / 已裁决 / 已上诉 / 执行阶段」（映射中国民诉与劳动仲裁阶段）；落款按学生行为底线。
- **C 级重写：** 面向法院/仲裁委加入「须律师签署」硬约束（美式版是 student attorney under supervision 可以签署，中式必须律师）；「Local rules 变化」的 [核实] 标注保留但内容改为「本地法院/仲裁委现行格式」。
- **D 级新增：** 「本 skill 不做的事」加入「不以学生名义签发正式对外文件」；stage 词汇加入「执行阶段」（民诉法第 246 条 2 年申请执行期间是中国民诉的关键后续阶段，美式版没有单独列）。
