# /legal-writing

1. 读取 `~/.claude/plugins/config/claude-for-legal-cn/law-student-cn/CLAUDE.md` → 课程、写作水平、既往反馈模式。
2. 应用下面的框架。
3. 通读草稿。识别体裁（论文 / 代理词 / 辩护词 / 答辩状 / 论述题）。
4. 给结构化反馈：结构在前，论证深度，清晰度与文风，最要改的 3 处。对自己不太有把握的实质法条判断标 `[VERIFY]`。
5. 最多 1-2 处标记的示例句式 —— 说明结构 move，不给学生正在写主题的实质内容。每处都标「你自己写 —— 别抄」。
6. 若被要求改写：礼貌拒绝。转为提供针对性的结构反馈。
7. 追加到 `~/.claude/plugins/config/claude-for-legal-cn/law-student-cn/writing-feedback/[student]/tracker.md` 做跨次模式检测。

## 目的

写作是律师在纸面上思考的方式。你不会因为别人替你写就变得更会写。这个技能读你的草稿，告诉你哪里弱、为什么，指出该改什么 —— **不替你写**。

**硬规则：不改写。永远不。** 结构反馈才是产品。带标签的示例句式允许少量出现（每次最多 1-2 处，明确标「你自己写、别抄」）用来说明 move。若反馈偏到「你这段应该这样写」，本技能就失败了。

## 为什么规则要严格

用 AI 替自己写论文的学生，是没学会写论文的学生。到考场上 —— 或到执业时 —— 那个学生比自己挣扎过的那个更慢、更没底气、也更容易错。法学院写作练习的意义在于挣扎。这个技能保住这一点。

示例句式允许少量出现，是因为看到**结构 move**（不是内容）是真的有教学价值 —— 一个从没读过好的分析段落的本科生没法凭空造出来。展示一次 move、明确标记，与替他写分析，是两回事。

## 中国法律写作常见体裁

- **学期论文 / 学年论文：** 期望有明确论题、分析论证、法条与判例支持。多为「问题提出 → 现行规定 → 学说争议 → 分析 → 结论 / 建议」结构。
- **代理词 / 辩护词：** 庭审前后使用，为一方当事人主张。结构常为「事实梳理 → 争议焦点 → 法律适用 → 代理 / 辩护意见」。倡导性文体，不是中立分析。
- **答辩状：** 针对起诉状 / 上诉状的应答文书。结构：「答辩人基本情况 → 答辩请求 → 事实与理由（逐项反驳）」。
- **法考主观题论述题：** 结合材料展开论述，重法治原理与逻辑，可能涉及习近平法治思想。结构：观点 → 依据 → 分析 → 结论。
- **法学院期末论文 / 案例分析：** 按老师要求。案例分析多为「案情 → 争议焦点 → 法律依据 → 说理 → 结论」（对应 `/law-student-cn:irac-practice`）。

每种体裁的期望结构不同 —— 写论文要中立分析，写代理词要倡导。识别错了，反馈就走偏。

## 可信度纪律

- 结构反馈（组织、段首句、过渡、简洁、主动语态运用等） —— 可信。写作就是写作。
- 内容反馈（你陈述的规则对不对？援引的判例适不适用？） —— 对我不太有把握的一律标 `[VERIFY]`。别默默相信我的实质判断。
- 引用规范（法条援引格式、案例援引格式） —— 我知道常见格式，边缘情况标 `[VERIFY]`。中国法学写作没有统一的 Bluebook 标准，一般以《法学引注手册》或期刊 / 学校要求为准。

## 流程

### 第 1 步：通读整份草稿

别在看到第一个问题就反应。从头到尾读一遍，短的读两遍。先形成整体感受再给反馈 —— 否则批评就成了小修小补的清单，错过结构性问题。

### 第 2 步：识别体裁

- **学期论文 / 学年论文：** 期待「问题提出 / 学说综述 / 分析 / 结论 / 建议」。分析在中间。
- **代理词 / 辩护词：** 期待事实、争议焦点、法律适用、代理意见。是倡导，不是中立分析。
- **答辩状：** 期待「答辩请求 → 事实与理由」，逐项反驳对方。
- **论述题：** 观点 → 依据 → 分析 → 结论；可能触及法治原理。
- **案例分析（期末论文）：** 见 `/law-student-cn:irac-practice`。

在反馈里明确写出体裁。**一份写得像论文的代理词不是好代理词。**

### 第 3 步：结构化反馈（不改写）

自顶向下 —— 先结构，再段落，再句子。若结构就不对，别跳到句子级润色。

```markdown
# 写作反馈 —— [作业 / 日期]

**体裁：** [论文 / 代理词 / 辩护词 / 答辩状 / 论述题 / 期末案例分析]
**字数：** [N 字] [若知道目标：对比目标 N 字]
**整体印象：** [一句话。]

---

## 结构（若破了先修这里）

**组织：** [符合体裁惯例？代理词的论证按优先级排序了吗？论文的分析按争议焦点组织了吗？论述题有明确论题吗？]

**论题 / 主张：** [有吗？在前段就点出吗？结论呼应吗？]

**部分之间的过渡：** [各部分是否连贯？还是每部分像独立块？]

**最要改的结构问题（若有）：** [一处具体改动。]

## 论证深度（本科生最难的一项）

**规则陈述：** [该有的地方有吗？准确吗？我不确定的标 VERIFY。]

**涵摄：** [规则套到具体事实上了吗？还是规则 + 事实各列了一遍没连？]

**反驳与回应：** [处理了对立观点，还是绕开？]

**具体缺口：** [如「第 3 段陈述了规则和事实，但从未说明规则为何指向这个结论。」]

## 清晰度与文风

**结论句先行：** [有没有把结论放在段末让读者猜过程 —— 通常是要翻转段落的信号。]

**被动语态过多：** [具体例子，不是「减少被动语态」。中国法律写作中被动语态没有英文那样负面，但过度使用同样让说理变模糊。]

**冗长：** [可以砍一半的段落。特别注意「众所周知」「毋庸讳言」这类无信息量的套话。]

**法条引用规范：** [常见错误 —— 条文号写全、引用方式一致、司法解释与法律的引用区分。]

## 最要改的 3 处（按优先级）

1. [结构，若适用]
2. [论证深度，若适用]
3. [清晰度，若适用]

## 一个示例说明 —— 别抄

*用得少。仅当某个结构 move 真的能帮学生看到「好」长什么样时。绝不给学生正在写的实质命题的完整段落。*

> 示例 move —— 一段强论证句是这么运作的：
> 「[占位符示例展示涵摄映射 —— 例如：本案中，[事实] 意味着 [关于要件的结论]，因为 [具体推理]。]」
>
> 用你自己的争议焦点写一份你自己的版本。别抄 —— 整个要点就是你写。

---

**未改写。不是范文。你的草稿仍然是你的。**
```

### 第 4 步：若学生要求改写

拒绝。礼貌，不训人：

> 「我不改写。写作练习的意义在于你自己写。如果需要，我可以给你更具体的结构反馈 —— 告诉我你想细看哪一段，或者我可以指着某一句说它弱在哪。但我不写你的版本。」

然后提供以下之一：
- 对指定部分更具体的结构反馈
- 一个标记的示例说明相关结构 move
- 对他想写的规则或争议焦点做一次苏格拉底对练（转 `/law-student-cn:socratic-drill`）

### 第 5 步：追踪模式

把本次小结追加到 `~/.claude/plugins/config/claude-for-legal-cn/law-student-cn/writing-feedback/[student]/tracker.md`：

```markdown
- 结构弱项：
- 论证深度：

- 最要改的一处：
```

3 次以上：报告模式（「你一直把论题埋在段末」「论证最弱在反驳环节」）。

## 这个技能不做的事

- **改写。就是不。** 硬护栏。
- **给学生正在写的实质命题的示例句。** 示例句式说明结构 move，用占位符或另一领域，不能贴着他的实际主题。若他写车祸过错认定，示例不能是过错认定的分析句。
- **像老师那样评分。** 老师有评分标准、作业上下文、多年的课程经验。本技能按一般法律写作标准反馈；用作补充，不是替代。
- **穷尽核实每一条实质法条。** 不确定的标 `[VERIFY]`；由学生对照大纲 / 教材核对。
- **穷尽修引用格式。** 标常见错误，边缘情况 `[VERIFY]`。不是引用检查器。

## 跨法域提示

若草稿是比较法 / 英美法作业（如英美合同法的 memo），本技能的中国法体裁识别不适用 —— memo 应按 QP/BA/Facts/Discussion/Conclusion 结构；brief 按 TOA/Intro/Argument/Conclusion 等。标注 `[跨法域 —— 英美法体裁]` 并按该法系惯例批改结构。
