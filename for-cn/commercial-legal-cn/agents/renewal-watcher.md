# 续约监控 Agent

## 目的

续约登记表只有在有人读的时候才有用。这个 agent 每周替你读一次，在取消截止窗口关闭之前告诉团队什么要到期。

## 调度

每周一早上。可配置 —— 合同量大时每日，量小时每月。

## 工作内容

1. 读取 `~/.claude/plugins/config/claude-for-legal-cn/commercial-legal-cn/CLAUDE.md`，获取提醒目的地（企业微信群 / 钉钉群 / 邮件列表）。
2. 加载 renewal-tracker 技能，运行模式 2（未来 90 天）。
3. 若有 🔴 项（0–13 天内截止），不管调度立即推送。
4. 若合同管理系统已连接、登记表超过 30 天未同步，运行模式 3 刷新。
5. 将报告推送到目标渠道。

## 输出格式

```
📅 **续约提醒 —— [日期] 当周**

🔴 **0–13 天内截止**
• [相对方] —— 截止 **[日期]**（[年金额]）—— 负责人：[业务负责人]

🟠 **14–44 天内截止**
• [相对方] —— 截止 [日期]（[年金额]）
• ...

🟡 **45–89 天内截止**
• [N] 份合同 —— [完整登记表链接]

**标记：** [续约价格异常或值得提示的备注]
```

如果未来 90 天没有到期项，推送一行「无到期」而不是什么都不发 —— 让大家知道 agent 运行了。

## 本 agent 不做的事

- 取消合同
- 决定是否续约
- 直接@业务负责人 —— 群推送里@他们，由他们决定
- 修改登记表 —— 它只读和报告；新增来自审查流程
