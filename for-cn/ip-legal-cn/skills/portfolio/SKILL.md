# /portfolio

浮现什么在续展、加资产、记录缴费、审计登记簿。

## 指令

1. **走下方工作流** 并读 `~/.claude/plugins/config/claude-for-legal-cn/ip-legal-cn/portfolio.yaml`

2. **默认（无参数）：** 等同 `--report` —— 按紧迫性分组显示未来90天的期限（🔴失效/宽展、⏰在窗口内到期、🟡即将到来、🌐代理管理、❓未知）

3. **`--report [--days N]`：** 模式2。用 `--days` 改窗口（30/60/90/180典型）。总是前置按CLAUDE.md → 输出的工作成果头部。总是以核验警告结尾

4. **`--add`：** 模式3。交互式走新资产——类型、法域、号、日期、拥有者、业务负责人。若法域非内置捕获自定义规则

5. **`--update`：** 模式4。记录续展/年费缴纳、与IP管理系统同步或改变资产状态。任何期限设 `已缴` 前执行有后果动作门槛

6. **`--audit`：** 模式5。更广健康检查——期限卫生、注册缺口、使用商标撤三风险、拥有者不一致、失效地平线、未监控商标

7. **登记簿为空且IP管理系统连接时：** 提供模式1——从记录系统拉组合并初始化登记簿

8. **护栏提醒：** 计算的期限仅供参考。每个输出以指导用户在申请或缴费前对**CNIPA商标网/专利电子申请系统/中国版权保护中心或相关登记机构**核验的一行结尾。docketed-but-wrong期限创建虚假信心；不让用户视此为记录系统除非IP管理系统同步集成

## 示例

```
/ip-legal-cn:portfolio
```


## 更好连接

本技能追踪你告诉它的期限。连接到以下时工作得多好：

- **IP管理系统（IPMS）通过MCP** —— Anaqua、CPA Global、Clarivate IPfolio、AppColl、智慧芽、Alt Legal、FoundationIP。**中国本土：** 智慧芽（IP管理版）、软唐、集佳事务所内部系统。**连接的IPMS给完整卷宗、维护费日程与来件通信在一处**，非登记簿是律师记得粘贴的什么。问你IPMS供应商他们是否有MCP连接器
- **CNIPA直接** —— 拉状态、期限与通信为整个组合而非一次一份申请。**通过CNIPA专利电子申请系统 https://cponline.cnipa.gov.cn 与商标网上服务系统 https://sbj.cnipa.gov.cn 直接检索**。不当前作为MCP可用；`CONNECTORS.md` 中愿望清单

无以上时，粘贴你卷宗或上传电子表格我从那追踪

## 目的

**商标注册未按时续展可能失效**（商标法第40条：期满前12个月+宽展期6个月+逾期失效）。**专利未按时缴年费失效**（专利法+实施细则）——**中国有权利恢复期但需交纳滞纳金+权利恢复费**。**软著登记不影响权属但影响证据**。所有这些都可避免，且都取决于一件事：**正确期限在某人日历上、绑到正确注册号、正确法域**

本技能维护那个日历

## 重要：期限参考警告

> 本技能应用的期限规则反映技能构建日期公开可用要求。**IP局要求、宽展期、费用结构与维护日程会变**。**总是在行动前对CNIPA商标网、专利电子申请系统、中国版权保护中心、马德里国际注册、EUIPO eSearch、UKIPO在线记录或相关国家登记机构核验计算的期限**。若用智慧芽、Anaqua、CPA Global、Clarivate、Alt Legal或其他IP管理系统，**他们的卷宗对你资产是权威**——用本追踪器组织并浮现他们数据，非替换
>
> **docketed-but-wrong期限比undocketed更糟**：创建虚假信心。**"最近无期限"输出特别值得二看再依赖**

## 法域与类型假设

维护机制按法域与资产类型不同：

### 中国商标（商标法）
- **注册有效期：** 10年，自核准注册日起（**第39条**）
- **续展：** 应当在期满前12个月内办理续展手续；未办理的可以给予6个月的宽展期；仍未办理的注销其注册商标（**第40条**）
- **续展后有效期：** 每次10年
- **马德里国际注册指定中国：** 10年+另有WIPO续展规则
- **无美国式§8使用声明**——但**撤三风险**：任何人可对**连续3年不使用**的注册商标向CNIPA提起撤销（**第49条**）

### 中国专利（专利法+实施细则）
- **发明专利：** 保护期**20年**（自申请日起）
- **实用新型：** 保护期**10年**（自申请日起）
- **外观设计：** 保护期**15年**（2021.6.1后申请）/**10年**（之前申请）
- **年费缴纳：** **从授予专利权当年开始按年缴纳**——**实施细则规定年费递增**
  - 发明专利1-3年900元；4-6年1200元；7-9年2000元；10-12年4000元；13-15年6000元；16-20年8000元
  - 实用新型/外观设计1-3年600元；4-5年900元；6-8年1200元；9-10年2000元
  - **小微企业与个人可减免85%（个人）或70%（小微企业）**
- **滞纳金+权利恢复期：** 未按时缴年费，可在**6个月宽展期内**加**滞纳金**（每逾1个月加缴当年年费的5%）缴纳；宽展期后**未按时缴的权利终止**，但可在**权利终止后2个月内**申请恢复（**恢复费1000元+补缴年费+滞纳金**）
- **PCT进入中国国家阶段：** 优先权日起30个月（或31个月延展）

### 中国著作权（著作权法）
- **一般规则：** 著作权自作品完成时产生（第2条）
- **作者身份：**
  - **自然人作者：** 财产权保护期**作者终生+死后50年**（第23条）——**注：与美国终生+70年不同**
  - **法人作品/职务作品/视听作品：** 保护期**首次发表后50年**（第23条）——但作品完成后50年内未发表的不再保护
- **人身权保护期：** 署名权、修改权、保护作品完整权**不受限制**（**永久**）
- **无强制登记与续展要求**——**登记非权利产生要件；软著另有登记流程**

### 软件著作权（计算机软件保护条例）
- **登记：** 由**中国版权保护中心**办理登记；**登记非权利产生要件但为重要证据**
- **保护期：** 自然人**终生+死后50年**；法人50年
- **无强制续展**

### 域名
- 年度或多年按注册商续展；典型30天宽展然后**赎回期**（~30天高费用）然后丢弃
- **中国 .cn/.中国域名：** 由CNNIC管理，规则类似国际但另有实名制要求

其他法域资产在组合中时，**在登记簿 `custom_rules` 块捕获维护机制**并报告将它们浮现为 `agent_managed` ——与外国代理确认状态而非本技能不理解计算日期

## 模式1：初始化

登记簿不存在或用 `--rebuild` 时跑

### 第1步：确定来源

读 `~/.claude/plugins/config/claude-for-legal-cn/ip-legal-cn/CLAUDE.md`：
- **IP管理系统连接**（Anaqua、CPA Global、智慧芽等）：通过其集成拉组合。**IP系统是权威源**；此登记簿镜像并不加系统未有的期限
- **无IP管理系统但电子表格/导出可用：** 请用户共享导出。导入存在的；标记任何缺注册或授权日的资产为 `unknown` 用于期限计算
- **手边无：** 交互式走资产——类型、法域、号、关键日期、拥有者

### 第2步：对每个资产，计算期限

应用文件顶部规则。填 `next_deadlines` 用两三个最近即将到来项——较远期限（数十年后10年续展）在报告期间按需计算而非投机性存储

**对技能无法自信安排的资产：**
- 未知法域规则 → 在 `custom_rules` 下加stub并标 `agent_managed: true` 附TODO与外国代理确认
- 计算需要的缺日期（专利无授权日、商标无注册日）→ 设 `next_deadlines` 空附 `notes` 中说明并初始化摘要中列资产为 `unknown`

### 第3步：写登记簿

在配置路径生成 `portfolio.yaml`。显示摘要：

```
组合登记簿已初始化

资产：[N]
  商标：[N]   ([N已注册] / [N审查中])
  专利：[N]   ([N发明+N实用新型+N外观设计] / [N申请中])
  软件著作权：[N]
  一般著作权：[N]
  域名：[N]

计算期限：[N]
代理管理/法域待定：[N] —— 与外国代理确认
未知（缺关键日期）：[N] —— 依赖报告前填

运行 /ip-legal-cn:portfolio --report 查看到期
```

## 模式3：加

```
/ip-legal-cn:portfolio --add
```

交互式加单个资产。问：

1. 类型（商标/发明专利/实用新型/外观设计/著作权/软件著作权/域名）
2. 法域
3. 商标或标题/发明名/作品名
4. 拥有者（记录拥有者——**与营业执照一致**——对续展/年费缴纳/权属证明关键）
5. 关键日期（按类型：申请、注册、授权、优先权、失效）
6. 号（**注意各类型号格式：** 商标注册号XXXXXXX；发明ZL2021xxxxx.x与授权公告号CN112xxx；实用新型ZL2021xxxxx.x；外观设计ZL2021xxxxx.x；软著登记号2021SR0xxxxx；著作权作品登记号国作登字-2021-XX-XXXXXXX）
7. 类别/权利要求数量
8. 主体规模（大/小微/个人——影响专利年费减免）
9. 来源——是否在IP管理系统卷宗下追踪？
10. 外部律师/外国代理（如有）
11. 业务负责人（这对谁重要——产品线、品牌经理）

## 模式5：审计

```
/ip-legal-cn:portfolio --audit
```

超本月期限的更广健康检查：

**期限卫生**
- 现在任何 `grace` 状态期限？（进行中但产生滞纳金）
- 未标 `abandoned` 或 `cancelled` 的任何 `lapsed` 资产？或恢复（若在恢复期）或更新状态
- 无 `next_deadlines` 计算的任何资产？或缺数据或技能不知道的法域

**注册缺口**
- 商标申请提交>18个月仍 `pending`？标记到局状态检查——可能需要答复审查意见
- 专利申请提交>4年仍 `pending`？标记申请检查——发明专利可能需答复审查意见
- **实用新型/外观设计申请：** 通常6个月内应有决定——标记>1年仍pending

**使用与撤三风险（仅商标）**
- **注册满3年商标：** 是否有使用证据保存？（**商标法第49条撤三风险**——任何人可提起撤三）
- 使用证据是否至少每年更新（发票、合同、宣传材料、销售记录、包装设计等）？
- 使用范围是否与注册核准使用商品/服务一致？（部分类别未使用可能被撤三）

**权属卫生**
- 任何 `owner` 非当前活跃主体（按主体登记，如可用）的资产？标记——可能需转让登记
- 跨资产拥有者名不一致（同主体，不同名字符串）？浮现清理——**必须与营业执照一致**
- **企业名变更/主体重组未更新登记？** 需办理商标/专利/著作权变更登记

**失效地平线**
- 未来24个月失效的任何专利？即使无维护期限，业务可能想知道——产品规划、续案策略、许可窗口
- **发明专利到期后进入公有领域**——业务可能想利用竞争对手到期专利技术

**未监控资产**
- 任何注册商标不在CLAUDE.md → 品牌保护监控清单？标记为缺口让律师决定是否加

**主体减免申报**
- **小微企业/个人专利年费减免：** 是否每年确认符合减免条件？企业成长可能失去减免资格

## 交接

- 接收：来自申请技能的新资产记录（申请提交或商标清出时）、来自清查技能（商标采用与申请排队时）与转让登记
- 发送："立即续展"触发到律师——本技能不办理任何东西；告诉律师期限与要带什么

## 本技能不做的事

- **不办理任何东西。** 它浮现的每个动作由律师或**外国代理**执行
- **不对CNIPA商标网、CNIPA专利电子申请系统或任何其他登记核验期限。** 它从你给它的日期计算它们。**登记簿是工作副本；登记是真相源**
- **不决定是否续展。** 续展是**商业call**——商标是否仍在使用、专利是否仍有价值、域名是否仍重要。本技能浮现期限与成本；业务与律师决定
- **不替代IP管理系统对多百资产组合。** 智慧芽、Anaqua、CPA Global、Clarivate、Alt Legal与类似系统有直接登记feed、期限自动化与年费缴纳服务。**本技能最适合较小组合，或作为浮现记录系统显示什么的轻量层**
- **不读局记录核验状态。** 此处显示"filed"的商标续展意味有人告诉它——非CNIPA接受。**通过CNIPA商标网或IP管理系统确认接受**

## 转换决策

**级别：B（大改）** —— 保留组合追踪架构（初始化/报告/加/更新/审计）、YAML登记簿结构、状态值（upcoming/due_soon/overdue/grace/lapsed/filed）、有后果动作门槛、代理集成：

- 商标续展从US §8/§9/§15（5-6周年使用声明+10年续展+§15不可争议） → 中国商标法第40条（10年+期满前12个月+宽展6个月+逾期失效）
- **撤三风险新增**：中国商标法第49条连续3年不使用可撤销——本技能持续监控使用证据（美国无此概念，只有类似§8使用声明）
- 专利年费从US 3.5/7.5/11.5年维护费+主体规模 → 中国按年递增年费+6个月宽展期+滞纳金+2个月权利恢复期（含恢复费）
- 专利保护期：US utility 20年 → 中国发明20年/实用新型10年/外观设计15年（2021.6.1后申请）
- 主体规模减免：US small/micro entity → 中国小微企业85%减免/个人70%减免
- 著作权：US 1978后无续展 → 中国无需登记与续展；作者终生+50年（vs美国+70年）；软著单独登记流程（中国版权保护中心）
- 数据库：USPTO TSDR/PatentCenter → CNIPA商标网+CNIPA专利电子申请系统+中国版权保护中心
- 域名：US registrar rules → 中国 .cn/.中国域名CNNIC+ICP备案要求
- 保留：登记簿位置模式、期限状态、有后果动作门槛、代理集成、决策立场、大输入处理
- 新增：撤三风险监控（第49条）作为独立deadline类型
- 新增：中国实务字段——ICP备案（域名）、软著登记号格式、著作权作品登记号格式、专利号格式（含发明/实用新型/外观设计不同前缀）、使用证据保存清单
- 新增：主体名与营业执照一致性审计（中国实务要求）
- 新增：企业名变更/主体重组转让登记（企业变更后需办理商标/专利/著作权变更登记）
