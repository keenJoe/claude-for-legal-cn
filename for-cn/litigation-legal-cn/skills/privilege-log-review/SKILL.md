# 律师保密与工作产品复核

## 已披露文书使用限制

处理一批诉讼文书前，问：「这批文书是通过法院调取、对方举证质证程序中收到、还是行政/监管机关移送？」若"是"：

- **民诉法与证据规定：** 通过法院调取或证据交换获得的、含商业秘密或个人隐私的文书，有使用限制（民诉法第 68 条 —— 涉及国家秘密、商业秘密和个人隐私的证据应当保密）。将其用于此案外的其他事项、其他诉讼、商业目的，可能违反证据保密要求，甚至触犯反不正当竞争法第 9 条（商业秘密）或个保法。
- **保护令 / 保密令：** 若法院或双方签署过保密协议约束该批文书，按协议执行。
- **其他法域：** 若批文书涉及境外调取（如香港、境外仲裁），核对当地规则。

确认：「本次使用在本案范围内，或已获授权/相对方同意，或文书已合法公开。」未确认则标：「⚠️ 已披露文书可能有使用限制。使用前确认合规。」

## 案件上下文

**案件上下文。** 检查 `CLAUDE.md` `## 事项工作区（案件文件夹）`。litigation-legal-cn 默认 `Enabled: ✓` —— 每案独立工作区。若 `✗`（一次做一案），跳过此段用执业级。若启用且无活跃案件，问：「这是哪个案件？运行 `/litigation-legal-cn:matter-workspace switch <slug>` 或说 `执业级`。」加载活跃案件的 `matter.md` 作上下文与本案覆盖项。输出写到案件文件夹。跨案件读取仅在 `Cross-matter context: on` 时。

## 目的

一批待对外提交的文书里，通常有三种：**明显应保密**、**明显可提交**、**需要思考的**。本 skill 把前两种分好，让律师的时间全用在第三种上。

**这是第一遍。律师复核每一个标注。无例外。**

## 出处忠实 —— 页码与引用覆盖度

本 skill 引用规则、地方细则、类案（律师保密规则、律师执业行为规范、举证质证规则、证据规定关于举证期限、保密义务的规定）时两条规则适用。

**页码引用必须支撑整个命题。** 若复核引一条规则或类案支撑多要素命题（例如"日志须描述每份文书且仅可对预期诉讼准备的材料主张保密"），核验页码是否覆盖每个要素。若只覆盖一项，拆分或收窄。引用只支撑部分主张的页码，会在对方指出后主张被驳回。这是"页码不支撑"失败模式：引用存在、原文存在，但原文不支撑命题。

**先抽取所有引用，再逐一核对。** 参见 brief-section-drafter 同款覆盖度要求。

## 加载上下文

`CLAUDE.md` —— 保密标注格式、复核规程。

**利益冲突门槛 —— 不可绕过。** 复核前检查 `_log.yaml`。若无：拒绝并路由到 `matter-intake`。

**法域重要。** 律师保密义务（律师法第 38 条）、律师执业行为规范中的保密规则、证据规定关于诉讼代理人保密（第 96 条）在中国内地大陆法域下适用。若案件涉及**香港、澳门、境外仲裁、外国法院**，保密规则可能不同（例如香港有 legal professional privilege / litigation privilege 制度，与内地律师保密义务概念相近但适用范围不同；欧盟竞争程序下企业内部法务通讯不受保护 —— *Akzo Nobel*）。若涉外，本 skill 结论可能不适用当地。

## 第 0 步：核对本案适用的保密规则

**复核开始前，核对本案适用的保密规则**（民诉法、证据规定、律师法、律师执业行为规范；若涉外则加对应法域规则）。识别：律师-委托人通讯的保密范围、律师工作产品的保护、单位内部法务通讯的保密（中国无 in-house counsel privilege 的独立制度 —— 单位法务的通讯以「因执业需要知悉的委托人事务」认定，但边界模糊；参见律师法第 38 条对律师的适用）、豁免情形、放弃/破坏保密的边界。引出原始条文。

**不做隐性补充。** 若对配置的检索工具查询规则或类案返回稀薄或无结果，如实报告并停。见 brief-section-drafter 同款规则。

**来源标注。** 每处规则引用附来源标注。标 `verify` 者伪造风险更高。

**保密破坏的规则：**

- **律师-委托人保密的破坏** 在中国实务中较少有明确"主题涵盖式破坏"规则，但一旦文书自愿披露给第三方（尤其对方），后续再主张对同类文书保密会较难获法院支持。核对本案适用的具体规则。
- **单位法务的通讯** 在民事诉讼中的保护无独立法条依据。实务中常参照律师保密义务或商业秘密（反不正当竞争法第 9 条）。若单位法务与外聘律师有明确委托关系，通讯保护相对确定；若单纯是单位内部法律部门与业务方沟通，保护弱。

## 三种判断

**三态规则。本 skill 绝不悄悄替律师做主观判断。** 任何不确定 —— 主导目的不明、诉讼预期是否已合理形成有争议、涉及法律与商业混合内容、涉及不确定第三方参与 —— 本 skill 保留保密标注并加 ⚠️ 让律师复核。**漏标破坏保密（单向门）；多标复核中修正（双向门）**。宁可可恢复的错。

**单位内部法务通讯在中国法域下无独立特权保护。** 分类时：

- **单位法务与外聘律师的通讯**（主导目的是取得法律意见）：主张保密相对可靠（律师法第 38 条 + 委托合同）。
- **单位法务与业务方的内部通讯**（主导目的是取得法律意见）：主张较难，需依赖商业秘密（反不正当竞争法第 9 条）或类推律师执业规则。**别将"确定保密"标签用在单位内部法务通讯上；标为「⚠️ 待律师判断」并注明可依据的基础。**

### 明显应保密（✅）—— 保留保密标注，不加旗

- 委托人与外聘律师之间取得/提供法律意见的通讯，无第三方在场
- 律师工作产品，为已发生或合理预期的诉讼准备的
- 律师-委托人保密圈内的策略讨论

### 不确定 —— 保留保密标注 **且** 加旗（✅ + ⚠️）

任何不明显在 ✅ 或 ❌ 的默认走这里。本 skill 不基于自己对主观检验的判断撤保密标注。例如：

- **单位法务同时做法律和商业工作** —— 这条通讯是法律意见还是商业建议？主导目的的判断是律师的，不是 skill 的。
- **第三方在场** —— 第三方是否属于保密圈（并案代理、代理人、共同利益关系）还是他的在场破坏保密？保留标注；旗给律师。
- **法律与商业混合的文件** —— 部分法律部分商业。部分遮蔽？整份保密？可披露？保留标注；旗给律师决定处理方式。
- **附件** —— 分别分析并保留各自标注，除非明显 ❌；旗依赖主观判断的项。
- **诉前工作产品** —— "合理预期的诉讼"是事实细节问题；保留标注；旗。
- **潜在放弃保密风险** —— 之后的分享历史有歧义；保留标注；旗放弃保密的问题。

每个旗记录具体开放问题与两侧证据，让律师无需重新读文书即可决定。

### 明显可披露（❌）—— 建议撤销标注，但记录评估

仅用于毫不含糊的情形。输出仍记录评估理由供律师抽查；不擅自从日志中撤销标注。

- 无任何律师参与
- 商业建议 + 律师抄送（抄送法务不构成保密）
- 底层事实（事实本身不受保密保护 —— 关于事实的通讯可能）
- 明显在保密圈外的第三方抄送（破坏保密）
- 附件本身不属于保密材料（邮件可能保密；附的销售数据表格不）

任一项"接近"—— 第三方可能是代理人、抄送法务可能是就法律事项询问 —— 归入不确定，旗。

## 工作流

### 第 1 步：格式检查

日志/清单是否具备必要字段？

| 字段 | 有？ |
|---|---|
| 日期 | |
| 作者 | |
| 收件人（TO、CC、BCC 全部） | |
| 文书类型 | |
| 主张的保密依据（律师-委托人保密 / 律师工作产品 / 商业秘密 / 个人隐私 / 综合） | |
| 描述（足以评估但不透露保密内容） | |

缺字段 → 标注在实质复核前补齐。

### 第 2 步：逐条

每一条：

```
条目 [N]（[编号]）：[✅ 保密 | ✅ 保密 + ⚠️ 旗 | ❌ 建议可披露（已评估）]
[若 ✅（无旗）：一句话原因]
[若 ✅ + ⚠️：保留标注；律师需回答的具体问题；两侧证据]
[若 ❌：一句话原因 —— 但标注在律师撤销前留在日志上]
```

**绝不产出基于本 skill 自身主观判断悄悄撤保密标注的条目。** ❌ 是记录在旗旁的建议；律师决定行动。

### 第 3 步：模式旗

跨日志：

- 同一问题重复出现？（例如同一第三方出现在 50 条 —— 一个判断解决 50 个旗）
- 过度标注模式？（一切都标而不区分 —— 抛给律师，但收窄的决定是律师的，不是 skill 的。漏标破坏保密；多标可修正。）
- 描述过泛？（描述模糊到法院可能要求当庭审查）

## 转换决策

- 分级：**C 重写**。原版基于美国 FRCP 26(b)(5)(A) 的 privilege log 制度 + attorney-client privilege / work-product doctrine，中国民诉无同等成文制度。工作流保留（第 0 步核对规则 → 三态判断 → 逐条 → 模式 → 输出），但整体重定为**律师保密义务筛查**（律师法第 38 条 + 证据规定第 96 条诉讼代理人保密 + 反不正当竞争法第 9 条商业秘密）。删除 Akzo Nobel / 欧盟竞争程序 privilege 讨论（仅涉外时留一句提示）；删除 FRCP 26(b)(5)(A) 与 US 联邦/州 privilege log 规则，换为中国实务的"对外提交前保密筛查"概念；删除 Kovel、Upjohn 等判例；删除 waiver doctrine 讨论中的美国州联邦差异，改为中国实务下自愿披露给第三方后主张同类保密较难获支持的一般原则。保留"三态"规则、模式检测、临界判断由律师决定的核心方法论。

## 这个 skill 特别不做的事

- 做临界判断。⚠️ 意味着"人决定"。任何主观检验（主导目的、诉讼预期是否合理、共同利益范围、后续分享是否破坏保密），skill 保留标注并加旗。
- 基于自身评估从日志上剥离保密标注。❌ 是记录给律师的*建议*，不是对日志采取的行动。
- 提交或不提交文书。它建议；律师决定；律师行动。
- 保证 ✅ 判断的正确性。日志由律师负责。这是第一遍。
