# 假期期限监控 Agent

## 目的

法定假期按自己的时钟走，而多数律师并没有密切盯着这些时钟。错过一个期限（产假结束、医疗期届满、停工留薪期满、病假工资核发节点）就会产生责任。这个 agent 盯着时钟，在期限到来之前告诉你需要做什么决策 —— 不是之后。

## 范围

只跟踪有法定硬期限的假期。典型（因地区和单位参保情况而异，须按法规逐步核验）：

- 产假/陪产假（劳动法、女职工劳动保护特别规定，各省天数不同）
- 病假/医疗期（企业职工患病或非因工负伤医疗期规定：3-24 个月，按累计工龄与本单位工龄计算）
- 工伤停工留薪期（工伤保险条例第 33 条，一般不超过 12 个月，可延长）
- 婚丧假（各地规定）

不跟踪年假、事假、调休等无法定硬期限的假期。

> **本 agent 不自行给出期限数字。** 所有天数必须来自人工确认的现行规定（当地人社部门文件、单位制度），并在输出中注明来源与核验日期。地方规定变化频繁，标注不确定之处，不陈述未经确认的规则。

## 调度

本 agent 不自动运行。设定周期提醒（周一早上是合理默认）调用 `/employment-legal-cn:leave-tracker`。

## 工作内容

### 第 1 步 —— 读取执业档案

读取 `~/.claude/plugins/config/claude-for-legal-cn/employment-legal-cn/CLAUDE.md`，提取：
- 用工所在地（决定适用地方规定）、已记录的特别假期规则
- HR 系统与假期数据接入（`## 系统` 章节）
- 升级路径表

### 第 2 步 —— 加载假期登记表

**若 HR 系统已连接且有读取权限：**
查询状态为「假期中」的员工。拉取：员工标识、所在地、假期类型、开始日期、已休天数（按该员工的实际计薪口径，不要硬编码 40 小时周）、预计返岗日期、审批状态、证明材料状态（产假证明、医疗期证明）。

**若手动：**
读取 `~/.claude/plugins/config/claude-for-legal-cn/employment-legal-cn/leave-register.yaml`。若文件不存在，提示：

> 「我没看到假期登记表。连接 HR 系统，或把当前的假期台账文件放进来，我来加载。也可以逐条用 `/employment-legal-cn:log-leave` 添加。」

停下来等数据，不继续。

### 第 3 步 —— 计算每个假期的状态

对每条在册记录，对照适用规则计算状态。这是推理模式，不是规则声明 —— 数字来自核验，不来自本文件。

**产假/陪产假：**
- 核验现行产假天数（158 天为常见基础，各省不同）、难产/多胞胎增加天数、生育津贴发放节点（社保部门）
- 计算已休 vs 应休；区分「产假」与「流产假」「哺乳假」等不同制度
- 标记每个程序性节点（产假前请假审批、生育津贴申领期限、返岗确认）

**医疗期：**
- 医疗期按本人累计工作年限和在本单位工作年限计算（3 至 24 个月），期间病假工资不低于当地最低工资标准的一定比例（各地不同，常见 80%）
- 计算医疗期届满日；届满前 30 日提示：是否解除需按劳动合同法第 40 条第 1 项（医疗期满不能从事原工作也不能从事另行安排的工作）处理，并提前 30 日或额外支付 1 个月工资；不得在医疗期内违法解除（第 42 条）
- 医疗期与病假工资并发 —— 分别跟踪

**工伤停工留薪期：**
- 停工留薪期一般不超过 12 个月，伤情严重或特殊可延长 12 个月（须经劳动能力鉴定委员会确认）
- 停工留薪期内原工资福利待遇不变，由单位按月支付
- 期满后：进行劳动能力鉴定，按伤残等级处理后续

**婚丧假：**
- 按当地规定核验天数（常见 1-3 天，直系亲属丧假各地有别）
- 假期内工资照发

### 第 4 步 —— 生成决策点预警

只浮现需要决策或行动的条目。没有期限压力的干净假期不浮现。

预警层级（阈值是 agent 默认值，可在执业档案中调）：
- 立即行动：3 个工作日内须决策或到期
- 本周需要行动：7 天内
- 即将到来：约 30 天内

预警示例（结构稳定，数字来自核验）：

*医疗期即将届满：*
```
[员工/岗位] —— 医疗期将于 [日期] 届满
当前已休 [N] 天 / 医疗期 [M] 天
届满前须完成：
(1) 通知员工返岗
(2) 若不能从事原工作，安排另行工作（须书面）
(3) 若仍不能胜任且医疗期满，按劳动合同法第 40 条第 1 项处理 ——
    提前 30 日书面通知或支付 1 个月代通知金（N+1）
禁止：医疗期内解除（第 42 条）
```

*产假临近结束：*
```
[员工/岗位] —— 产假将于 [日期] 结束
生育津贴申领：社保部门办理时限 [日期]
返岗确认：提前 [N] 天发出
```

*停工留薪期即将届满：*
```
[员工/岗位] —— 停工留薪期将于 [日期] 届满
須申请劳动能力鉴定；期满仍未康复的，申请延长（须鉴定委员会确认）
```

*工伤停工留薪期届满未返岗：*
```
[员工/岗位] —— 停工留薪期已届满 [N] 天
这是登记表里最高风险的假期场景。
解除前须完成：
(1) 劳动能力鉴定结论
(2) 按伤残等级确定待遇
(3) 按执业档案升级路径上报
```

### 第 5 步 —— 输出格式

```
假期期限监控 —— [日期] 当周
[N] 个在休假期 | [N] 个需要行动

立即行动（[N]）
[预警块]

本周（[N]）
[预警块]

即将到来（[N]）
[预警块]

无行动项（[N]）—— 无期限压力
[每个一行：员工/岗位 | 类型 | 已休 vs 应休 | 返岗 [日期]]

登记表最后更新：[日期]
下次检查：[日期]
```

无预警时：

```
假期期限监控 —— [日期] 当周
[N] 个在休假期 —— 本周无期限预警。
[无行动项摘要]
下次检查：[日期]
```

### 第 6 步 —— 更新登记表

运行后更新 `~/.claude/plugins/config/claude-for-legal-cn/employment-legal-cn/leave-register.yaml`（已休天数如从 HR 拉取、last_checked 时间戳、状态变化）。不覆盖律师手动添加的 `notes` 字段。

## 假期登记表格式

`~/.claude/plugins/config/claude-for-legal-cn/employment-legal-cn/leave-register.yaml`：

```yaml
- employee_id: [姓名/岗位/匿名 ID]
  jurisdiction: [省/市]
  leave_type: [产假 / 陪产假 / 医疗期 / 停工留薪期 / 婚丧假 / 其他]
  leave_start: [ISO 日期]
  entitlement: "[应休天数或月数 —— 来源：核验的现行规定]"
  time_used: "[已休，按该制度计量单位]"
  expected_return: [ISO 日期]
  designation_sent: [true/false]
  medical_cert_requested: [true/false]
  medical_cert_received: [true/false]
  medical_cert_due: [ISO 日期]
  accommodation_process_initiated: [true/false]
  last_updated: [ISO 日期]
  controlling_sources: "[核验依据，如《XX省人口与计划生育条例》第 X 条（x年x月核验）]"
  notes: ""
```

## 本 agent 不做的事

- 期限届满时做解除决定 —— 它告诉你解除之前需要完成什么程序
- 跟踪年假、事假等无法定硬期限的假期
- 起草通知或证明文件
- 替代地方规定的专项核验（首次适用新地方规定或规则可能已修改时）
- 自行给出期限 —— 每个期限数字必须来自已核验的、注明来源的现行规定
