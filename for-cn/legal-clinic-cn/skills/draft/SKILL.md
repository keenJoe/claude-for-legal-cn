# 起草：初稿生成

## 目的

学生在初稿上花大量时间，而教学价值在分析与策略而非在敲抬头和「兹为……」。本 skill 从案卷与纠纷类型模板产出初稿，让学生的时间用在思考上。

**每份初稿都明确是起点。** 不是终稿。学生分析、修改，老师审核，才能出。

## 加载上下文

`~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/CLAUDE.md` → 纠纷类型、模板、办案地（法院、仲裁委、已录入地方规定）、监督模式。

案卷或接待摘要提供事实。

## 教学姿态检查

读该纠纷类型的老师指引 `~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/guides/<纠纷类型>.md`。查 `pedagogy_posture`：

- **`guide`（默认）：** 出结构与清单。请学生起草每段。给反馈（措辞、可读性、必备要素、漏了什么）。学生试过一次才提议填某段。
- **`assist`：** 出成果。标出待学生复核项。学生改动中学习。
- **`teach`：** 不出成果。请学生起草。给反馈。学生卡住时用引导性提问。两次尝试后才给一段范例，且只给那一段。跟踪对错让老师看到进步。

无指引用 `guide`。有指引但没设姿态用 `guide`。

无论姿态，输出总包含：「**教学模式：[assist/guide/teach]** —— 由你老师的指引设定。含义：我做了 [X]、学生做了 [Y]。」

**办案地假设。** 初稿默认 CLAUDE.md 里的法院、仲裁委、地方规定。抬头、当事人称谓、送达要求、页码限制、格式与实体规则在不同办案地有实质差异。若案件在不同法院、跨省，依赖前与老师核对。

## 工作流

### 第 1 步：哪份文书？

对齐诊所模板集。按纠纷类型的常见集：

| 纠纷类型 | 文书 |
|---|---|
| **劳动** | 劳动争议**仲裁申请书**（**仲裁前置**）、答辩状（劳动方或用人单位方）、证据清单、代理词、劳动关系确认申请 |
| **婚姻家事** | 起诉状（离婚 / 抚养 / 探望 / 财产分割）、答辩状、财产清单、人身安全保护令申请书、赡养费诉状 |
| **交通事故 / 人身损害** | 起诉状、诉前保全申请、赔偿计算表、答辩状、责任划分复核申请 |
| **民间借贷** | 起诉状、答辩状、**支付令申请**（民诉法督促程序）、和解协议 |
| **消费维权** | 12315 投诉举报书、起诉状、退一赔三主张说明 |
| **房屋租赁 / 物业** | 起诉状、答辩状、律师函（**须指派/合作律师签发**） |
| **刑事辩护援助（值班律师）** | 值班律师法律帮助记录、认罪认罚具结见证记录（律师签署，学生辅助）—— **学生不出庭、不代理** |

请求的文书不在模板集：「诊所模板没 [X]。我可从一般规则试起草，但重度标记 —— 未经本诊所或办案地校准。更好办法：请 [指导老师] 是否已有模板。」

### 第 2 步：收事实

读接待摘要或案卷。文书需要每一项事实：有没有？

| 文书需要 | 有吗 | 来源 |
|---|---|---|
| [事实] | ✓ / ✗ | [接待 / 受援人材料 / 需要去取] |

缺必需事实 → 不猜。标：`[缺事实：受援人劳动合同签订日 —— 从劳动合同或问受援人取]`。

### 第 3 步：应用办案地

按 `~/.claude/plugins/config/claude-for-legal-cn/legal-clinic-cn/CLAUDE.md` 办案地：

- **抬头 / 当事人称谓：** 法院 / 仲裁委的现行格式。若已录入地方规定，用；否则用一般规则并标：`[核实抬头：本地规定未加载 —— 对照 [法院/仲裁委] 当前指引确认]`
- **送达要求：** 谁被送、送达方式（EMS 邮寄 / 直接送达 / 电子送达）、时限
- **本地要点：** 页数、字体、递交份数、立案窗口。已录入的应用；未录入的标记。

### 第 4 步：起草

用纠纷类型模板。能从事实填的填。占位符明确 —— 绝不用「看起来对」的编造填。

**文书里每一处法律断言：** 是学生要核验的假设，不是 skill 承诺的结论。相应标记。

**中式特色：**
- **仲裁前置提示：** 劳动争议直接起诉的一定要先仲裁（除劳动争议调解仲裁法第 47 条终局裁决情形）—— 若客户带着诉状来，标 `[核实：劳动争议须先仲裁，若已有裁决书附上；否则本诉状应改为仲裁申请书]`
- **诉讼时效 / 仲裁时效提示：** 涉时效将届的情形，在起诉状事实与理由部分明示相关时效计算逻辑
- **公章与签字：** 涉法人一方，涉签字盖章要求核实（企业出具的证据应加盖公章，最高法民诉证据规定 `[待核验条文号]`）
- **管辖：** 民诉法第 35 条协议管辖须与争议有实际联系；劳动争议管辖按用工地或用人单位所在地
- **律师函：** 学生**不能**以律师名义发律师函。若要出律师函，标 `[必须由指派/合作律师签发，学生仅辅助起草]`

### 第 5 步：标不确定

三种在文书内联的标记：

- `[缺事实：……]` —— 文书需要案卷没有的事实
- `[核实：……]` —— 提交前需核对的法律或事实断言
- `[不确定：……]` —— skill 真的拿不准，直说而不是猜

### 第 6 步：监督路由

向法院/仲裁委提交材料是重大行为。关卡是档案 `## 监督模式` 里的监督流程 + 第 0 部分角色核验。**向法院/仲裁委提交的材料一律走监督审核再提交**，无论选了哪种监督模式。

- **正式队列：** 初稿入队，学生看到「已入队等待 [指导老师]」
- **可配置标记：** 该文书类型属触发条件时输出加「提交前请 [指导老师] 确认」标
- **轻监督：** 标准 AI 辅助标注，无额外关卡 —— 但**向法院/仲裁委提交仍走既有监督流程**

**出庭代理提醒：** 学生不代理出庭。以受援人名义正式提交或参加庭审的部分由**指派/合作律师**承担（学生辅助）。

## 本 skill 不做的事

- **不出终稿。** 只出初稿。学生修改，老师审核，律师签发/提交（若需要）。
- **不猜缺失事实。** 标出来让学生去取。
- **不定法律理由。** 用常见路径；是否合适由学生定。
- **不代做办案地检索。** 应用已录入的地方规定；未录入或可能已变的标出。
- **不签发律师函 / 不做出庭代理相关。** 由指派/合作律师承担。学生不能以律师名义发律师函。

## 转换决策自检

- **A 级直转：** 6 步工作流、教学姿态检查、事实收集表、内联 3 类标记（缺事实/核实/不确定）、监督路由三档、学生复核清单结构。
- **B 级大改：** 文书类型全面重写（I-589 asylum → 劳动仲裁申请书；eviction answer → 民事答辩状；protective order petition → 人身安全保护令申请书；FDCPA demand → 消费者投诉举报书；motion to change venue → 管辖异议申请书）；抬头 / 服务规则从州法院 → 法院与仲裁委双轨；办案地感知从「州 + 地方规则」→「法院管辖 + 仲裁委指引 + 地方性法规」。
- **C 级重写：** 「Filing with court/agency is a consequential action」+ Part 0 role check → 加入**仲裁前置**（劳动）、**律师函须律师签发**、**学生不代理出庭**三条中式特色关卡；「ABA Formal Op. 512」引用替换为「法律援助法与本诊所行为准则」；「student attorney under supervision」→「学生辅助 + 指派/合作律师签发」的双层结构（美式一层 attorney supervision，中式必须点出律师承担实质工作）。
- **D 级新增：** 「诉讼时效 / 仲裁时效提示」在起草时明示相关计算逻辑；「公章与签字」中式特色（企业证据加盖公章要求、法人签署有效性）；「管辖」段区分民诉协议管辖（第 35 条）与劳动争议管辖；「支付令申请」（民诉法督促程序）作为民间借贷可选路径；「认罪认罚具结见证记录」中值班律师签署 + 学生辅助的分工。
