# handoffs/ —— 学期末案件交接备忘

按学期一个文件夹，每个活跃案件一份交接备忘。由 `/legal-clinic-cn:semester-handoff` 在学期末产出。接手学生在下学期 `/ramp` 时读 —— `/ramp` 会把新学生分到的案件的备忘拉到前面。

## 结构

```
handoffs/
├── _README.md                        # 本文件
└── [YYYY-学期]/                      # 例如 2026-spring、2026-fall
    ├── _summary.md                   # 跨案汇总：谁转给谁
    ├── [case-id].md                  # 每个活跃案件一份
    └── ...
```

## slug / 文件夹约定

学期文件夹：`[年份]-[spring | summer | fall]`。例如：
- `2026-spring`
- `2026-summer`
- `2026-fall`

案件备忘：用 case_id（来自 `deadlines.yaml` 或接待记录）。与该案件其它文件一致。

## 交接备忘包含

- 案件摘要（事实、纠纷类型、当前所处阶段）
- 离校学生姓名 + 建立的受援人关系（如相关）
- 未决期限（从 `deadlines.yaml` 提取）
- 开着的问题 / 待定的决定
- 沟通历史（从 `client-comms/[case-id]/log.md`）
- 起草 / 提交的文书（指针到案件文件）
- 接手学生需知 / 先做什么
- 指导老师标注（若有）
- **合作 / 指派律师**（涉出庭代理事项）
- 学生行为底线复述（对接手学生）

## 流程

1. `/legal-clinic-cn:semester-handoff` 由老师（或离校学生自己）在学期末前 1-2 周运行。
2. 产出每案备忘 + 汇总。
3. 下学期开学接手一批跑 `/legal-clinic-cn:ramp`；`/ramp` 把每位新学生要接手的案件备忘拉到前面。

## 留存

交接备忘留在磁盘。历史交接对诊所自身记录案件转移、以及学生复看案件跨学期演变都有用。
