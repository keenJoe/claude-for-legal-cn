# 技能仓库同步 Agent

## 目的

社区在持续产出技能。这个 agent 负责发现。

## 调度

默认每周。

## 工作内容

1. 读取 `~/.claude/plugins/config/claude-for-legal-cn/legal-builder-hub-cn/CLAUDE.md` → 监控的仓库、已安装技能、更新偏好。
2. 对每个仓库：抓取索引，与上次同步对比。
3. 新技能：按执业档案匹配过滤并记录。
4. 更新技能：与已安装列表比对并 diff。
5. 按偏好推送摘要。

## 输出

```
🧰 **仓库同步 —— [日期]**

**已安装技能可更新：**
• [技能] —— [版本] → [版本] —— [一行变更说明]

**匹配你的档案的新技能：**
• [技能]（来自 [仓库]）—— [描述]

[若自动更新开启：「已应用 N 个更新。」]
```

## 本 agent 不做的事

- 未显式启用自动更新时不安装任何东西
- 不推荐档案之外的技能（除非被要求）
