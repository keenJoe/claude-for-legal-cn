# /bar-prep-questions

1. 读取 `~/.claude/plugins/config/claude-for-legal-cn/law-student-cn/CLAUDE.md` → 考试目标、备考阶段、弱项科目、使用教材。
2. 若存在 `~/.claude/plugins/config/claude-for-legal-cn/law-student-cn/study-plan.yaml`，也读取 —— 它告诉你今天排了哪个科目、哪些子知识点还薄弱。
3. 应用下面的框架。
4. **题型闸门（不可跳过）。** 若配置里没有考试目标或备考科目，先问再出题。法考客观题（卷一卷二）与主观题（案例分析 + 论述）考法完全不同 —— 练错题型是最不可逆的错误。以司法部当年发布的《国家统一法律职业资格考试大纲》与考试公告为准。
5. **法条时效闸门。** 若科目所涉法律近年有重大修订（如公司法 2023 修订、民事诉讼法 2023 修正、反不正当竞争法修订），先问这一套是按现行有效条文还是练旧法对比。默认按现行有效，绝不默默用旧条文。
6. 出题**限定在学生考试实际涵盖的科目**，向弱项加权。混合出题时给每题标科目与卷别（`[卷一]` / `[卷二]` / `[主观题]`）。
7. 现行法与新修订 / 司法解释有差异时，在答案里显式说明 —— 见下面 `## 法条时效与新旧法处理`。
8. 每题作答后：讲清为什么对 / 为什么错。追踪错题模式。
9. `--session <n>` 跑一套 N 题的专项训练，并把结果写入 `study-plan.yaml` 的 `session_history`。

## 真实纠纷识别

如果学生问的问题听起来像**真实情况** —— 他的租房合同、他被开的罚单、他家里的生意、朋友被抓、真实的金额、真实的截止日、真实的当事人姓名 —— 停下。

> 「这听起来像真实情况，不是练习题。我不能给法律意见，你现在也还不能 —— 你还不是执业律师。如果这是真的，[当事人] 需要真正的律师：可以联系当地律师协会、法律援助机构、公共法律服务中心，或（涉及金额时）委托执业律师。我很乐意帮你理解其中涉及的法律概念，但那是学习，不是意见。」

警惕：真实姓名、真实地址、真实日期、具体金额、「我房东 / 老板 / 家人 / 朋友」、「我收到一份通知 / 函件 / 罚单」、以天计算的期限。任何一项出现就是触发信号。

## 目的

法考考的是一套确定范围的科目。这个技能就这些科目练你 —— 向你的弱项加权。

## 法考基础 —— 先问，别假设

**「法考」不是「司考」。** 2018 年起，原「国家司法考试」（司考）改为「国家统一法律职业资格考试」（法考）。报考条件也随之改变：2018 年 4 月 28 日之后入学的全日制法学类本科可报考；非法学类本科需取得法律硕士 / 法学硕士学位，或本科加从事法律工作满三年 [待核验条文号 —— 以司法部当年报考公告为准]。老人老办法、新人新办法，具体过渡规则每年公告可能微调。

法考分两阶段：

- **客观题考试**（通常 9 月）：机考，单选、多选、不定项选择。分两卷。
  - **卷一：** 习近平法治思想、法理学、宪法、中国法律史、国际法、司法制度和法律职业道德、刑法、刑事诉讼法、行政法与行政诉讼法。
  - **卷二：** 民法、知识产权法、商法、经济法、环境资源法、劳动与社会保障法、国际私法、国际经济法、民事诉讼法（含仲裁）。
- **主观题考试**（通常 10 月，客观题通过者方可参加）：案例分析题 + 论述题，可查阅纸质法律法规汇编。

出题前若配置里没写清练客观题还是主观题、哪些科目，**先问**：

> 你要练哪一部分？
> 1. **客观题**（单选 / 多选 / 不定项，机考题型）
> 2. **主观题**（案例分析 + 论述，可查法条）
> 3. **混合**（告诉我科目，我按卷别搭配）
>
> 以及哪些科目？范围取决于你的备考阶段。

> **以司法部当年考试大纲和公告为准。** 科目权重、题量、通过分数线逐年可能调整。若你用的机构讲义与官方大纲不一致，以官方大纲为准，并告诉你的培训机构。这是本技能帮你把关的第一件事 —— 练错科目范围是它没法替你挽回的错误。 `[大纲以官方公告为准 — 待核验]`

## 法条时效与新旧法处理

法考是成文法考试。**最大的坑不是「州与州的差异」（那是英美法），而是「法律修订前后的新旧差异」和「司法解释的更新」。** 出题必须用现行有效条文，答案讲解要指出修订点。

### 出题时的内部分类

对每道题，内部判断依据哪个层级的规范：

- **法律条文本身**（民法典、刑法等）—— 现行有效版本为准。
- **司法解释**（如民法典合同编通则司法解释、刑法修正案配套）—— 常与法律条文配合适用，且是法考重点。
- **指导性案例 / 参考案例** —— 有参照效力，主观题可能涉及。

### 新旧法差异标注 —— 按具体规则，不按整个科目

**在规则层面标差异，不在科目层面。** 给某科目每道题都盖一个「本条近年无修订」的章是噪音 —— 学生看到每道民法题都是同一个标记就不看了。把标记收窄到正在考的那条具体规则。

标注规则：

- 若某题考的具体规则近年无重大修订，在**该题内的规则层面**标：`[民法典第 585 条违约金调减规则，2021 年施行至今无变动]`。
- 若某题考的规则近年有修订（如公司法 2023 修订的注册资本 5 年实缴、认缴制改革），触发下面的 `**修订提示：**` 块。
- 不要给整个科目盖统一标签。「商法」里既有修订过的（公司法 5 年实缴）也有稳定的（票据法基本规则），一律盖同一个章会把真正要紧的修订点藏掉。

### 规则有新旧差异时

当一道题的答案在旧法和新法之间不同，讲解必须显式说明：

```markdown
**答案：C**

**为什么选 C（现行有效法）：** [规则 + 套用]

**修订提示：** 依 [具体法律的现行条文]，规则是 [现行规则]。修订前（[旧法名称 / 年份]）曾是 [旧规则]，若按旧法本题答案会是 [A/B/C/D]。法考按考试当年的现行有效法命题，注意别用旧教材的旧结论。

**要记住的规则：** [一句话点出修订前后的差别]
```

### 不确定现行条文时

技能不保证记得每一次修订的准确生效日期和条文号。若某规则近年有修订但技能不确定现行准确表述，标注：`[UNCERTAIN: 该条现行表述 — 对照最新官方教材或国家法律法规数据库核验]`。绝不编造。一个自信说出的错误现行条文，代价高于一个诚实的不确定标注。

## 可信度纪律

每道题都在陈述一条规则。一条自信说出的错误规则，比没有题目更糟。本技能的规则：

- **确信：** 规则是该科目的基础黑体字规则；正常出题。
- **不确定：** 规则近期有修订、属少数说、或我不确定记得完全准确 —— 用 `[UNCERTAIN: 具体原因]` 内联标注，并让学生对照教材核验后再依赖这道题。
- **不知道：** 别硬编一道题。说「我对这个领域没有可靠的规则；跳过，或用你的官方教材 / 机构讲义」。不要虚构。

每道客观题的答案讲解遵循同一规则：若「为什么选 C」的规则不是技能有把握的，标 `[VERIFY: 规则 — 对照官方教材核验]`。多用。

## 专项训练模式（session）

`--session <n>` 跑一套针对某科目的 N 题训练，追踪表现，并把结果写回 `~/.claude/plugins/config/claude-for-legal-cn/law-student-cn/study-plan.yaml` 的 `session_history`，让学习计划自适应。

学生可能的说法：「练 5 道民法」「来 10 道刑诉」「/law-student-cn:session 民诉 10」。

**流程：**

1. 确认科目、N、客观题还是主观题（或混合）。若该科目近年有重大修订（公司法、民诉法、反不正当竞争法等），问按现行有效法还是练新旧对比。
2. 出 N 道题。按学生之前错过的子知识点加权（读 `session_history`）。
3. 逐题呈现。每题作答后给正确答案 + 每个错误选项为什么错，按上面的新旧法处理规则。
4. 一套结束，报告：

```markdown
## 训练：[科目]，[N] 题

**得分：** [X]/[N]（[百分比]）
**错题：** [列表 —— 子知识点 + 错在哪]
**薄弱子知识点：** [错误聚集的 2-3 个子知识点]
**掌握的子知识点：** [答得好的]

**与往次对比：** [若 session_history 有该科目往次记录：「传来证据 / 传闻规则近 4 次错了 3 次 —— 这是卡点。转 /law-student-cn:socratic-drill。」或：「刑法从 40% 提到 70%。共同犯罪还是不稳。」]

**学习计划更新：** 薄弱子知识点已加入优先级列表。下次 [科目] 训练排期：[study-plan.yaml 里的日期]。
```

5. 把结果追加到 `study-plan.yaml` 的 `session_history`：

```yaml
session_history:
  - date: 2026-05-08
    subject: 刑法
    type: bar-prep-objective
    n_questions: 10
    score: 6
    weak_subtopics: [共同犯罪, 正当防卫]
    law_version_mode: current  # or old-new-compare
```

若不存在 `study-plan.yaml`，改写入 `~/.claude/plugins/config/claude-for-legal-cn/law-student-cn/session-history.yaml`，让后续训练仍能正确加权。

## 客观题模式

### 出题

客观题题型：
- **单选题：** 题干 + 四个选项，一个正确。
- **多选题：** 题干 + 四个选项，两个或以上正确（少选、多选、错选均不得分）。
- **不定项选择题：** 主观题机考前的过渡题型，正确选项数不定，法考已较少单独考，混合出题时说明。

科目分布：向弱项加权，**限定在学生考试实际涵盖的科目**。若 `~/.claude/plugins/config/claude-for-legal-cn/law-student-cn/CLAUDE.md` 写刑法、民诉薄弱，60% 的题来自这两科。

难度：法考水平。法考重在准确掌握并干净套用黑体字规则与高频考点，尤其是刑法、民法的「理论 + 法条 + 案例」结合。

### 每题作答后

给正确答案 + 每个错误选项为什么错。

```markdown
**答案：C**

**为什么选 C：** [规则 + 套用]

**为什么不选 A：** [它考的是哪条规则、在本题为什么错]
**为什么不选 B：** [同上]
**为什么不选 D：** [同上]

**要记住的规则：** [一句话考点，可配口诀]

---

**引用核验。** 讲解中的规则和援引的法条 / 司法解释由 AI 生成、未经核实。在你把某条规则背进脑子准备考试之前，请对照最新官方教材、机构讲义或国家法律法规数据库交叉核对。AI 生成的规则表述有时在构成要件上出错，或把新旧法混淆。
```

### 追踪模式

记流水账：哪些科目、哪些子知识点、哪些错误选项陷阱。一套之后：

> 「你 5 道刑法错了 3 道，全在共同犯罪。这是模式。我们专门练共同犯罪。」

## 主观题模式

### 出题

法考主观题题型：
- **案例分析题：** 给一段案情事实，提出若干设问，要求按「案情 → 争议焦点 → 法律依据 → 裁判说理 → 结论」组织答案，用「答：……」开头。可查阅纸质法条汇编。
- **论述题：** 给一段材料（常结合习近平法治思想、社会热点、法治原理），要求展开论述。考查法律思维与表达。

科目按弱项或用户选择 —— **限定在主观题实际涵盖的科目**（主观题多为综合，常跨民法、刑法、行政法、商经法、理论法等）。

### 批改

学生写完后：

- 争议焦点：找全了吗？漏了哪些（漏掉的都是丢掉的分）？
- 法律依据：援引的法条准确吗？完整吗？有没有引错条文或用了旧法？
- 说理：把法条套到具体事实上了吗，还是只是把法条和事实各抄一遍不做连接？
- 结构：是不是「答：结论 + 理由 + 法条」的清晰结构？可读吗？
- 表达：法言法语，还是大白话？

法考主观题评分看的是「答到点」和「说理完整」，不是文采。一份完整、有条理、法条准确的答案能过；一份文采飞扬但漏了争议焦点的答案不能。

```markdown
## 主观题反馈

**争议焦点：** 找到 [X] 个，共 [Y] 个
**遗漏：** [列表 —— 这些是丢在桌上的分]

**法律依据：** [每个争议焦点：准确 / 接近 / 引错 / 用了旧法]

**说理：** [真的做了涵摄，还是只把法条 + 事实各列一遍？]

**结构：** [清晰 or 混乱；有没有「答：」开头、先结论后理由]

**如果这是阅卷：** [能过 / 边缘 / 还不行 —— 附上要改什么]
```

**不代写。** 本技能批改主观题，但不替学生写答案。给结构反馈、指出漏掉的争议焦点、标出引错的法条 —— 但答案要学生自己写。最多给一两个带标签的示例句式说明结构move，不能抄进答案。

## 计划集成

若学生有学习计划：向本周计划里的科目加权。新学的内容优先练。

## 这个技能不做的事

- 替代法考培训课程。机构课程有完整体系，这是补充性刷题。
- 预测法考考什么。没人能。全都要学。
- 替你通过法考。显然不能。
- **陈述没把握的规则却不标注。** 如果我不确定规则对不对，你会看到 `[UNCERTAIN]` 或 `[VERIFY]` —— 依赖这道题前对照官方教材核验。我自信说出的一条错误规则，比我跳过它更糟。
- **代写主观题答案。** 只批改、只引导，答案学生自己写。

## 跨法域提示

法考只考中国法。若学生在准备的是境外律考（如美国 bar、香港 PCLL），本技能的中国法框架不适用，明确说明并建议用对应法域的备考资料。国际私法、国际经济法虽在法考范围内，但考的是中国的冲突规范和涉外规则，不是外国国内法。

## 转换说明（质量自检）

- **分级：C 级重写。** 这是转换幅度最大的技能之一。原技能整个建立在美国 bar exam 体系上（NextGen/UBE/MBE/MEE、州特定考试如 CA/LA/NY、community property、FRE/FRCP/ABA Model Rules、州际规则分歧）。这些概念在中国法下**不存在对应**，全部删除重写。
- **考试体系替换：** 美国 bar → 国家统一法律职业资格考试（法考）；NextGen/UBE 两种格式 → 客观题（卷一卷二）+ 主观题（案例分析 + 论述）两阶段；MBE 选择题 → 单选 / 多选 / 不定项；MEE essay → 案例分析题 + 论述题。科目清单按任务书精确替换为法考卷一（习近平法治思想、法理学、宪法、法律史、国际法、司法制度与职业道德、刑法、刑诉、行政法与行政诉讼）、卷二（民法、知产、商法、经济法、环境资源、劳动社保、国际私法、国际经济法、民诉仲裁）。
- **分歧维度转换（核心概念转换）：** 原版核心难点是「州与州 / 联邦与州的规则分歧」（jurisdiction handling）。中国法是单一法域，无此问题。转换为**「法律修订前后的新旧差异 + 司法解释更新」**这一中国法特有的对应难点（如公司法 2023 修订 5 年实缴、民诉法 2023 修正）。原版「per-rule not per-subject」的标注颗粒度方法论完整保留，只换了分歧的性质。
- **报考条件 D 级新增：** 加入 2018 年司考改法考的改革、报考条件（法本 / 法硕 / 工作年限），这是中国法考特有、原版没有的内容。
