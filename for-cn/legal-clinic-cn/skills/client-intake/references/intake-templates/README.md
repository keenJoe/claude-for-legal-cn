# 按纠纷类型的接待模板

cold-start 从指导老师的接待登记表填充。若未提供，`/client-intake` 使用 SKILL.md 第 2 步的默认问题集。

每类一份文件：

- `labor.md` —— 劳动人事（用人单位、合同、社保、争议起因、证据、**仲裁时效 1 年**、是否已仲裁）
- `family.md` —— 婚姻家事（关系、子女、人身安全、现有裁判、冷静期与开庭日）
- `traffic-injury.md` —— 交通事故 / 人身损害（事故认定、保险、伤情、误工、**诉讼时效 3 年**）
- `private-lending.md` —— 民间借贷（借条、转账凭证、利率（LPR 4 倍上限）、还款进度、时效）
- `tenancy.md` —— 房屋租赁 / 物业（合同、押金、争议、证据、搬离与开庭时间）
- `consumer.md` —— 消费维权（经营者、凭证、损害、退一赔三 / 食品十倍）
- `criminal-aid.md` —— 刑事辩护援助 / 值班律师（涉嫌罪名、阶段、强制措施、认罪认罚从宽；**学生不会见、不出庭**）

每份模板包含：要问的问题（顺序）+ 敏感处理注（例如刑辩援助里问及涉嫌罪名时说明学生辅助边界 + 家暴问询时先确认询问环境安全）。
